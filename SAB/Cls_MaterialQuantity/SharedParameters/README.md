# SAB — файл общих параметров

`SAB_ОбщиеПараметры.txt` — единый файл общих параметров Revit для модулей SAB. Он содержит параметры классификации материалов `SAB_MT_…`, рабочий параметр `SAB_ЕдиницаПодсчета`, параметры изображений экспликаций и служебные параметры расчёта материалов по слоям. GUID каждого параметра постоянен и не должен изменяться.

`SAB_IMG_Эземпляр` следует привязывать как параметр экземпляра к категории «Стены». `SAB_IMG_Тип` следует привязывать как параметр типа к категориям «Окна» и «Двери».

Файл сохранён в UTF-16 LE. При последующих правках сохранять эту кодировку.

Новые имена строятся по схеме `SAB_<объект>_<свойство>`: например, `SAB_Материал_Имя`, `SAB_Материал_Описание`, `SAB_Материал_Модель`; для развёрток — `SAB_Развертка_<свойство>`. Коды модулей `MT` и `LV` в новых именах не используются. Названия свойств материала повторяют встроенные названия Revit. Существующие параметры с историческими именами и GUID сохраняются для совместимости.

`SAB_Материал_Имя`, `SAB_Материал_Описание` и `SAB_Материал_Модель` добавляются как общие параметры экземпляра в служебное семейство обобщённых моделей `SAB_РасчетныйСлой`. При пересчёте значения копируются из исходного материала и доступны в спецификациях обобщённых моделей. Эти поля не дублируются на самих материалах: источником остаются их встроенные свойства.

Сборка SAB поставляет этот файл в каталоге `SharedParameters` рядом с `SAB.dll`. Модуль пересчёта использует из него `SAB_ЕдиницаПодсчета` и служебные параметры расчётной записи. `SAB_MT_ЕдиницаПодсчета` остаётся параметром будущей схемы классификации; его внедрение выполняется только с переносом существующих значений.

Толщина, номер слоя и раздел АР/АИ относятся к применению материала в конструкции, а не к определению самого материала. Поэтому этих полей в разделе `SAB_Материалы` нет.
