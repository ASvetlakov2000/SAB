# Перенос существующих значений материалов — рабочая схема

Статус: на согласование. До проверки Excel и словаря значений в RVT ничего не переименовывать, не удалять и не привязывать к модели.

| Новый параметр | Откуда можно брать кандидата | Правило переноса |
| --- | --- | --- |
| `SAB_MT_Класс` | Класс/категория материала, заполненные пользовательские классификационные поля | Автоперенос только при однозначном совпадении с утверждённым словарём. Не выводить класс из категории стены или пола. |
| `SAB_MT_Группа` | Категория/группа материала | Нормализовать синонимы после просмотра примеров; исходное значение сохранить в Excel. |
| `SAB_MT_Подгруппа` | Дополнительная существующая классификация | Если поле описывает торговую марку, толщину или область применения, не переносить в подгруппу автоматически. |
| `SAB_MT_Теги` | Разрозненные дополнительные признаки | Переносить только свойства самого материала, а не свойства конкретного слоя или конструкции. |
| `SAB_MT_ЕдиницаПодсчета` | `SAB_ЕдиницаПодсчета`, `ADSK_Материал тип подсчета`, `ADSK_Единица измерения` | Приоритет явного SAB-значения; конфликтующие значения помечать на проверку. Допустимы `м`, `м²`, `м³`, `Не учитывать`. |
| `SAB_MT_ИмяВедомости` | `ADSK_Материал наименование`, «Группа модели» самого материала, имя материала | В данной модели «Группа модели» у 34 материалов в основном содержит читаемое название, а не группу классификации. Переносить после сравнения с ADSK и редактуры. Пустое новое поле означает использование имени материала. |
| `SAB_MT_ИмяМарки` | «Группа модели» самого материала, маркировка/краткое наименование | Переносить лишь если исходный текст достаточно краток и пригоден для марки на узле. Пустое поле означает использование имени материала. |
| `SAB_MT_Статус` | Явный признак библиотеки | Не считать отсутствие использования в одной модели основанием для архивации или удаления. |
| `SAB_MT_ID` | — | Создаётся и поддерживается плагином после разрешения дублей между моделями; Revit ElementId не годится как межмодельный ID. |
| `SAB_MT_Поиск` | — | Собирается плагином из утверждённых полей, вручную не правится. |

Параметры типов стен, перекрытий, потолков и крыш анализировать отдельно от параметров материалов. В этой модели «Группа модели» у типов содержит коды вроде `НЕС_ЖБ`, `УТП`, `ПГК`; это признак конструкции, не материал. Они могут дать контекст для ручной классификации, но не должны автоматически перезаписывать свойства одного материала, применённого в разных конструкциях. Для каждой неоднозначной строки Excel сохранять старое значение, предполагаемое новое и причину проверки.
