# SAB — материалы по слоям

Модуль основного плагина SAB для Revit 2022–2024. Панель `SAB → Материалы и ведомости` содержит одну команду `Пересчет материалов`. Она открывает общее окно настройки и обновления:

- в таблице можно искать, фильтровать и пакетно назначать единицы подсчёта материалов;
- кнопка `Пересчитать материалы` сохраняет изменённые правила, рассчитывает слои стен, перекрытий, составных потолков и крыш, агрегирует результат и создаёт две нативные спецификации Revit;
- перед расчётом окно настройки закрывается; ход обновления показывается в отдельном окне прогресса.

Загрузка служебного семейства и транзакции расчёта выполняются после закрытия модального окна настройки. Прогресс обновляет только отрисовку WPF, не обрабатывая пользовательский ввод внутри транзакций. После завершения команды однократно обновляются активный вид и окно Revit на следующем событии `Idling`, вне модальных окон и транзакций. При создании записей в новом проекте повторно используется сохранённое служебное семейство текущей версии Revit, чтобы не обновлять старый шаблон при каждом запуске.

Создаваемые спецификации:

- `SAB — Материалы по слоям — Черновая ведомость` — сгруппированные рассчитанные значения.
- `SAB — Материалы по слоям — Контроль` — агрегированные строки, в том числе с причиной, по которой количество не рассчитано.

Подробные строки `исходный элемент + слой` рассчитываются в памяти и сохраняются сжатым архивом в одном элементе `DataStorage`. Для нативных спецификаций создаются только агрегированные записи: готовые количества группируются по материалу и единице, диагностические — дополнительно по статусу, категории и типу конструкции. Поэтому число служебных экземпляров зависит от количества строк ведомости, а не от количества элементов модели. Первый запуск этой версии удаляет послойные экземпляры прежней архитектуры. Исходные конструкции команда не изменяет; Parts не создаются.

## Данные материала в спецификациях

Каждый агрегированный экземпляр семейства `SAB_РасчетныйСлой` содержит общие текстовые параметры экземпляра:

| Параметр | Источник |
| --- | --- |
| `SAB_Материал_Имя` | Имя исходного материала |
| `SAB_Материал_Описание` | Встроенный параметр материала «Описание» (`ALL_MODEL_DESCRIPTION`) |
| `SAB_Материал_Модель` | Встроенный параметр материала «Модель» (`ALL_MODEL_MODEL`) |

Значения обновляются при каждом пересчёте; пустые исходные значения очищают соответствующие поля записи. Эти параметры доступны в обычных спецификациях категории «Обобщённые модели». Обе создаваемые ведомости включают колонки «Материал: Имя», «Материал: Описание» и «Материал: Модель». В существующие ведомости добавляются только отсутствующие поля; настройки имеющихся колонок, фильтры и сортировка сохраняются. Старый параметр `SAB_Материал` продолжает получать имя материала для совместимости со спецификациями предыдущей версии. Служебное семейство автоматически получает недостающие параметры при первом пересчёте, без удаления агрегатов. Описание и модель также входят в подробный архив расчёта.

## Расчёт количества

Явное правило `SAB_ЕдиницаПодсчета` имеет приоритет. Если оно не задано, единица определяется по существующим параметрам `ADSK_Материал тип подсчета` или `ADSK_Единица измерения`. Окно «Пересчет материалов» позволяет назначить значения `м`, `м²`, `м³` либо `Не учитывать`; выбор `Авто (ADSK)` очищает явное правило. Общий параметр добавляется к категории материалов при пересчёте. Для м³ берётся `Element.GetMaterialVolume(materialId)`; для м² используется `объём материала / толщина слоя`. Число записывается в СИ в числовой параметр `SAB_Количество`. Для погонных метров, нулевой толщины, отсутствующего объёма и повторения одного материала в нескольких слоях одного элемента результат **не подставляется** — контрольная спецификация сообщает причину.

Метод `V/t` — только предварительный. Он требует сверки на проёмах, примыканиях, торцах, уклонах и слоях-мембранах; черновую ведомость нельзя выпускать как РД без этой проверки. Плагин пока пересчитывает данные **по кнопке**, не отслеживает изменения модели автоматически и не размещает спецификацию на листе. Пользователь может разместить созданную нативную спецификацию стандартным способом Revit.

## Сборка и установка

Модуль компилируется в составе `SAB\SAB.csproj` и входит в единую `SAB.dll`.
Устанавливается штатным MSI из папки `Installer\output`; отдельного проекта,
DLL и `.addin`-манифеста у модуля нет.

Версия сборки содержит год целевого Revit. Окна материалов загружают скомпилированную разметку по адресу с явной версией сборки, а стили — относительно этого адреса. Это предотвращает перенаправление ресурсов окна в сборку для другого года Revit при одновременной загрузке нескольких версий SAB.

Регрессионная проверка `Tools\MaterialQuantity\Test-CompiledResources.ps1` запускается в Windows PowerShell 5.1 с `-STA`. Параметры: `-AssemblyPath <полный путь к SAB.dll>`, `-RevitApiDirectory <папка API соответствующего Revit>`; необязательный `-ConflictingAssemblyPath <другая SAB.dll>` воспроизводит загрузку второй сборки после заполнения кэша WPF. Проверка создаёт скомпилированные окна материалов, прогресса и настройки заливок, проверяет подключение кнопки сохранения, закрытие модального окна до запуска расчёта, отсутствие обработки ввода при обновлении прогресса и сжатие подробного архива; документы Revit не изменяются. После обновления установленного плагина Revit следует полностью перезапустить, чтобы загрузить новую DLL.

После первого успешного пересчёта файл семейства можно открыть для проверки по пути `%LOCALAPPDATA%\SAB\MaterialQuantity\<версия>\SAB_РасчетныйСлой.rfa`. До первого запуска `.rfa` на диске нет.

## Испытание перед рабочим использованием

На копии проекта в Revit 2023 и 2024 проверить миграционное удаление старых послойных экземпляров, число новых агрегированных записей, итоговые суммы, подробный архив `DataStorage`, повторный запуск, смену слоёв и экспорт IFC/NWC. Сборка DLL не подтверждает работу этих сценариев внутри Revit.
