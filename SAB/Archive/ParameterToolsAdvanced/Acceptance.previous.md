# Проверка в Revit

Проверять на отдельной копии тестового проекта в Revit 2022, 2023 и 2024. Сборка и тесты ядра не подтверждают выполнение нативных операций Revit.

- [ ] Панель SAB / Параметры загружается; настройки находятся в меню заполнения, команды доступны для горячих клавиш.
- [ ] Выбрать пять параметров, корпус помещения, категории, этажи, константу 0; сохранить и переоткрыть настройки.
- [ ] По умолчанию ручной режим: выделить две стены → заполнить → выбрать помещение. Корпус, номер, имя совпадают с указанным помещением, этаж с матрицей, подземная часть равна 0.
- [ ] Выбрать помещение через его марку: получаются те же значения, что при выборе самого помещения.
- [ ] Escape при выборе помещения ничего не меняет, в том числе привязки категорий.
- [ ] Выделенные элементы разных помещений в ручном режиме получают данные одного явно указанного источника.
- [ ] Переключить настройку на автоматический режим: каждый элемент получает данные своего помещения за один запуск без дополнительного клика.
- [ ] Уведомление содержит количество обработанных элементов и список применённых параметров/значений.
- [ ] В автоматическом режиме стена/дверь между двумя помещениями попадает в отчёт неоднозначности и не получает случайное значение; в ручном режиме указанный источник применяется.
- [ ] Сложные стены/перекрытия/потолки, пересекающие несколько помещений: проверить ограничения определения по контрольным точкам.
- [ ] Изменить имя/номер/корпус исходного помещения: проверка выявляет устаревшие данные стен.
- [ ] Удалить исходное помещение: проверка сообщает о невозможности определить источник.
- [ ] В автоматическом режиме переместить элемент в другое помещение: проверка обнаруживает устаревшие значения и смену источника.
- [ ] В ручном режиме перемещение само по себе не меняет источник: проверка сравнивает с сохранённым явно выбранным помещением.
- [ ] Проверить разные корпуса на одном плане: нет зависимости от последнего ручного корпуса.
- [ ] Видимые элементы подложки другого этажа не переписываются номером активного плана.
- [ ] Отсутствующий параметр без галочки попадает в отчёт, остальные значения этого элемента не записываются частично.
- [ ] Включить галочку: недостающие привязки появляются у выделенной категории; прежние категории и их заполненные значения сохраняются.
- [ ] У остальных экземпляров добавленной категории появляется параметр, но не скопированные значения выделения.
- [ ] Проверка при включённой галочке не добавляет параметры.
- [ ] Отмена заполнения штатным Undo возвращает и значения, и исходные привязки категорий.
- [ ] Число 0/0,00 не подсвечивается как пустое значение.
- [ ] Снять подсветку, повторить проверку, сохранить, закрыть и переоткрыть: красные переопределения не остаются в модели.
- [ ] Исходные переопределения элемента и пользовательский временный режим вида сохраняются.
- [ ] Недоступный для записи элемент/параметр отражается в отчёте; результат остальных элементов явно указан.
- [ ] Ручной источник корпуса: короткий диалог назначает только корпус, последующее заполнение получает остальные значения из помещения.

Статус до пользовательской проверки: сборки и автоматические проверки ядра выполняются локально; тестирование на живой модели ещё не выполнено.

- [ ] Проверить только стены; затем только окна. Подсветка предыдущей проверки на текущем виде снята, остальные категории не окрашиваются.
- [ ] Отмена окна категорий не меняет значения, настройки и текущую подсветку.
- [ ] Поиск категории сохраняет галочки скрытых строк; Shift/Ctrl выделяют строки, пробел и кнопки применяются всему выделению.
- [ ] Количество корпусов 1, 5 и 10: добавление, удаление, сохранение, повторное открытие и ручной выбор работают.
- [ ] Независимо изменить название сущности и источник правила: изменения источников и значений сохраняются.

## Расширенные правила и 3D

- [ ] Открыть настройки на модели, содержащей служебные параметры без Definition: окно открывается, безымянные параметры отсутствуют в списке, остальные доступны. Исправлено по стеку `Catalog.SourceParameters`, строка 84, из журнала Revit 2023 от 03.10.2026.

- [ ] Добавить правило плюсом; сохранить с пустым параметром. Строка состояния указывает точную строку и действие, окно остаётся открытым.
- [ ] Оставить пустой источник помещения или константу. Попытка сохранения открывает соответствующее правило во вкладке «Источники».
- [ ] Источник корпуса «Из помещения», пустой неиспользуемый ручной список: профиль сохраняется.
- [ ] В ручном корпусе + и × внутри строки добавляют и удаляют названия; скрытые поиском категории сохраняют галочки.
- [ ] Настроить сущность «Несущие стены»: категория стены, параметр несущей конструкции = 1; ненесущие стены не заполняются и не проверяются этим правилом.
- [ ] Для двух правил одного целевого параметра задать разные условия. Каждый элемент получает одно подходящее значение; пересечение условий приводит к отчёту о конфликте.
- [ ] Проверить И/ИЛИ, пустые параметры, отсутствующий параметр условия, числовые сравнения, регистр и допуск.
- [ ] Рассчитать текст с номером и именем помещения; арифметику с запятой, скобками и делением на ноль. Ошибочные элементы не записываются частично.
- [ ] Зависимость A → B при обратном порядке строк работает; цикл A → B → A выводится в отчёте.
- [ ] Пробный расчёт не меняет параметры, привязки, сохранённый источник и подсветку; результат совпадает с последующим заполнением при неизменной модели.
- [ ] На 3D заполнить элементы: выбрать уровень из заполненной матрицы и помещение из списка. Проверить сохранённые источники, закрыть/переоткрыть проект и проверить снова.
- [ ] На 3D выделить элементы, ранее заполненные на разных этажах: проверка использует индивидуальные сохранённые уровни.
- [ ] Отмена выбора уровня или помещения в 3D не записывает значения. Удалённый/не заполненный уровень требует выбора доступного источника.
- [ ] В режиме «Уровень элемента» разные элементы на 3D сохраняют свои фактические уровни; выбор нужен только для элементов без уровня.
- [ ] Исходная графика: собственные цвета линий/заливки и веса → проверка → снятие подсветки. Исходные изменённые свойства восстановлены, прочие сохранены.
- [ ] Повторить после Undo/Redo, переключения вида и восстановления сохранённой сессии. Снимок и подсветка изменяются вместе.
- [ ] На старом красном виде запустить «Снять подсветку». Пересоздание вида не требуется; для утраченного снимка прочитать ограничение в инструкции.
- [ ] Проверить снятие подсветки кнопкой непосредственно внутри отчёта.
