# Заполнение и проверка параметров

Модуль встроен в основной `SAB.dll`. Устанавливается общим установщиком SAB для Revit 2022, 2023 и 2024.

## Первичная настройка

На вкладке **SAB → Параметры → Занести параметры ▼ → Настройки параметров** выбрать целевые параметры, включить нужные правила и категории.
Один профиль проекта используется для заполнения и проверки.

| Группа | Источник |
| --- | --- |
| Зона | Параметр корпуса выбранного помещения; альтернативно ручной корпус |
| Уровень | Матрица «уровень → номер этажа»; по умолчанию уровень текущего плана |
| Местоположение | Настраиваемая константа; по умолчанию `0` |
| Помещение | Номер, имя либо выбранный параметр помещения |

Источники корпуса и целевые параметры выбираются независимо. Поддерживаются существующие проектные параметры экземпляров, включая общие параметры. Числовой ноль считается заполненным значением.

Включённая галочка **«Добавлять отсутствующие параметры выбранным категориям при заполнении»** расширяет существующую привязку параметра. Она сохраняет прежние категории, GUID и заполненные значения. Параметр появляется у всей категории; значения записываются только выделенным элементам. Новые определения параметров не создаются. Проверка привязки не изменяет.

## Работа

1. Выделить элементы.
2. Запустить **SAB → Параметры → Занести параметры**.
3. Выбрать помещение или его марку. Появится уведомление с результатом и применёнными значениями.

Ручной выбор помещения установлен по умолчанию. Для автоматического поиска помещения выбрать этот режим в настройках: выделить элементы и запустить заполнение без дополнительного выбора. Неоднозначные источники требуют исправления и попадают в отчёт.

**Проверить параметры** сначала открывает компактное окно категорий с поиском и тумблерами. Проверяется только включённый набор: выделение, а без выделения — подходящие элементы текущего вида. Последний набор категорий проверки запоминается отдельно от категорий заполнения. При первом запуске включены только стены, если они есть в области проверки. Отсутствующие, пустые и не соответствующие профилю значения подсвечиваются красным; отчёт позволяет найти элемент. В ручном режиме используется сохранённое выбранное помещение. В автоматическом — помещение определяется заново.

**Снять подсветку** восстанавливает исходные переопределения графики и обновляет вид. Снимок изменённых свойств хранится в модели на виде, поэтому восстановление не зависит от состояния памяти плагина. Изменения графики и снимок записываются одной транзакцией. Кнопка также доступна внутри отчёта проверки. Перед сохранением и закрытием документа модуль также восстанавливает графику.

**Выбрать корпус** находится в **Настройках параметров → Источники → Корпуса для ручного выбора**, когда для выбранного правила задан источник **«Корпус вручную»**. Кнопка сохраняет настройки и открывает короткое окно назначения корпуса выделенным элементам. Основной режим корпуса — **«Из помещения»**.

Команды заполнения, проверки, снятия подсветки, выбора корпуса и настроек доступны для штатных горячих клавиш Revit. Настройки открываются отдельной командой.

Профиль и выбранные помещения хранятся в модели. После переноса из отдельного прототипа идентификаторы хранилищ сохранены.

## Отложенные возможности

Колесо по боковой кнопке мыши, контуры корпусов, связанные помещения и следующие режимы описаны в `Docs/ParameterTools_Backlog.md`. Выполнять их только после отдельного указания пользователя.

Сборки и тесты правил проверяются автоматически. Проверка нативных операций на живой модели перечислена в `Docs/ParameterTools_Acceptance.md`.

## Правила и понятное сохранение

Во вкладке **Правила** нажать **+**. Слева — название сущности (например, «Несущие стены»), справа — заполняемый параметр, далее — источник. Название можно свободно изменить; оно не определяет источник значения. Старые группы «Зона», «Уровень», «Местоположение», «Помещение» сохранены как начальные названия. Параметры показываются только по имени, без GUID; идентификаторы сохраняются внутри профиля.

Источники независимы для каждого правила: помещение, уровень модели, параметр самого элемента, постоянное значение, корпус вручную. Во вкладке **Источники** выбрать правило в списке и заполнить его настройки. Показываются только нужные источники. Для корпуса из помещения выбрать «Параметр помещения» и его параметр корпуса. Для номера и имени помещения использовать соответствующие встроенные поля.

Корпуса ручного режима добавляются **+** и удаляются **×** непосредственно в строках. Количество можно задать явно. Скрытый список ручных корпусов не мешает сохранению режима «Из помещения».

Строка состояния внизу показывает номер правила, недостающее поле, вкладку и необходимое действие. При неудачной попытке сохранить окно открывает вкладку и правило с первой ошибкой. После исправления сообщение обновляется; готовность подтверждается текстом «Настройки готовы. Нажмите “Сохранить”». Остальные ошибки доступны в подсказке строки состояния.

Во вкладке **Категории** список отделён рамкой. Работают поиск, Shift для диапазона, Ctrl для отдельных строк, массовое включение/выключение и пробел для переключения выделения. Категории, скрытые поиском, сохраняют состояние.

## Условия, шаблоны и формулы

Во вкладке **Условия** выбрать нужное правило. Можно дополнительно ограничить его категориями и условиями по параметрам элемента: равно / не равно, содержит, начинается с, числовые сравнения, пусто / заполнено. Условия объединяются **И** или **ИЛИ**. Без дополнительных категорий и условий действует общая область заполнения. Дополнительные категории пересекаются с общей областью, а не расширяют её.

Настройки шаблонов, формул и допуска раскрываются отдельно. `{value}` означает исходное значение выбранного источника. Доступны `{room.number}`, `{room.name}`, `{level}` (номер этажа из матрицы), `{param:Имя параметра}` (параметр текущего элемента).

Примеры:

- `Корпус {value}` — добавить текст перед исходным значением.
- `{room.number} — {room.name}` — объединить номер и имя помещения.
- `=({value} + 2) / 3` — арифметический расчёт.
- `={param:ADSK_Количество} * 2` — взять значение другого параметра элемента.

Арифметические выражения начинаются с `=` и поддерживают числа, +, −, *, /, круглые скобки. Запятая и точка допустимы в десятичных числах. Числа параметров читаются во внутренних единицах Revit. Запись чисел поддерживает параметры «Число», «Денежная единица» и целые числа; размерные целевые параметры требуют отдельного преобразования единиц и пока не записываются.

Если исходный параметр заполняется другим подходящим правилом, расчёт использует вычисленное значение независимо от порядка строк. Циклы и несколько подходящих правил для одного целевого параметра попадают в отчёт; значения проблемного элемента не записываются частично. Проверка повторяет тот же расчёт с заданными допуском и учётом регистра. Отбор выполняется по текущим значениям модели; элемент, переставший соответствовать условиям, выходит из области этого правила.

Команда **Пробный расчёт** в меню заполнения показывает текущие и рассчитанные значения выделенных элементов без записи значений или привязок. Она запрашивает те же источники, что заполнение. После оценки результата можно запустить «Занести параметры».

Пользовательская схема «отбор → расчёт → проверка» основана на изучении [официального руководства ModPlus](https://modplus.org/ru/revitplugins/mprparametrization). Это самостоятельная реализация SAB; все стратегии и функции ModPlus не воспроизводятся.

## Работа на 3D-виде

Если уровень нельзя определить выбранным способом, команда заполнения предлагает **заполненные строки матрицы уровней**. Выбранный уровень используется для этой операции и сохраняется с успешно заполненными элементами. Проверка на 3D использует сохранённый уровень; выбор запрашивается для элементов без действующего источника. На плане приоритет имеет уровень текущего плана, в режиме «Уровень элемента» — его фактический уровень.

Для ручного помещения на 3D открывается список размещённых помещений фазы текущего вида с поиском по номеру и имени. На плане сохраняется сценарий щелчка по помещению или марке. Отмена диалога источника отменяет заполнение без записи параметров.

Панель содержит один большой Split Button (заполнение, пробный расчёт, настройки) и две малые кнопки одна под другой (проверка с заполненной лупой, снятие подсветки с пустой лупой). Выбор корпуса доступен внутри настроек. Все окна используют рамку, заголовок и стили SAB по образцу разверток.

Для старой версии без сохранённого снимка команда снимает временный режим и очищает узнаваемую красную заливку проверки на текущем виде. Если прежние пользовательские цвета уже были перезаписаны и снимок утрачен, точное восстановление этих цветов невозможно; остальные свойства графики не сбрасываются.
