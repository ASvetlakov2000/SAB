# Архив условий и пробного расчёта

Снимок исходников до удаления вкладки «Условия» и команды «Пробный расчёт», 2026-10-04.
Файлы `.cs.txt` исключены из сборки. Активное заполнение использует выбранный источник без формул,
условий и отдельных категорий правила. Старые расширенные настройки сохраняются в
`Profile.ArchivedAdvancedRules` при следующем сохранении профиля.
Проверка заполненности использует фильтры вида и не сравнивает параметры с расчётным источником.
