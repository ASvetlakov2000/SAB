# Архив модулей SAB

Код в этой папке сохранён для истории и не входит в сборку `SAB.dll`.

- `Instructions` — команда открытия инструкций и её сервисы.
- `Regulations` — команды и настройки лендинга регламентов.
- `RoomGeometryTools` — модуль проверки геометрии помещений.

Если модуль потребуется вернуть, его нужно перенести в активную структуру проекта,
добавить исходники в `SAB.csproj` и явно зарегистрировать кнопку в `MainPanel`.
