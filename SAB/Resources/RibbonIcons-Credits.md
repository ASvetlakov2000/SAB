# Источники значков ленты

Значки предоставлены [Icons8](https://icons8.com). Файлы PNG поставляются с плагином
и доступны в Revit без интернета.

| Ресурс | Источник |
| --- | --- |
| ParameterIndex | [Index, Parakeet Line](https://icons8.com/icon/kN1MNn4lr0ao/index) |
| ParameterSearch | [Search, Forma Regular Filled Sharp](https://icons8.com/icon/3HmnX1ym1BDx/search) |
| ParameterSearchReset | [Search, Forma Regular](https://img.icons8.com/forma-regular/32/search.png) |
| MaterialDataSheet | [Data Sheet, Parakeet Line](https://icons8.com/icon/dTkBIBxBvvAy/data-sheet) |
| MaterialLayers | [Layers, SF Black Filled](https://icons8.com/icon/A2sfeYasHHVe/layers) |
| FilledRegionSettings | [Layers, Dotted](https://icons8.com/icon/57586/layers) |
| FilledRegionCreate | [Diagonal Lines, Cute Outline](https://icons8.com/icon/wioV3JEhCLZS/diagonal-lines) |

Стрелка и галочка параметров нарисованы средствами SAB поверх исходных значков.
Значок материалов объединяет таблицу данных и изображение слоя в правом нижнем углу.
