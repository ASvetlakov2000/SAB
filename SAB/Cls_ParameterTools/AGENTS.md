# Инструкции проекта

- Рабочая версия — заполнение и жёсткая проверка параметров с общим профилем.
- Основной сценарий: выделить элементы → команда заполнения → вручную выбрать помещение → уведомление со списком применённых параметров.
- Ручной выбор помещения является значением по умолчанию. Автоматическое определение доступно отдельной настройкой.
- Настройки открываются отдельной командой. Заполнение и проверка пригодны для штатных горячих клавиш Revit.
- Зона: корпус из параметра помещения; уровень: матрица уровней; местоположение: изменяемая константа; помещение: номер, имя и выбранные параметры источника.
- Автоматическое расширение привязок категорий — только по включённой пользователем галочке и только при заполнении. Сохранять существующие категории и заполненные значения.
- `../../../Docs/ParameterTools_Backlog.md` не является разрешением выполнять его задачи. Колесо по кнопке мыши, контуры корпусов и следующие вариативные режимы начинать только после отдельного прямого сообщения пользователя «работай по бэклогу» либо равнозначного указания. Не запускать по расписанию или автоматически.
- Поддерживаются Revit 2022/2023/2024. После изменений выполнять соответствующую сборку; нативные операции Revit не считать проверенными только по сборке и тестам ядра. Для базовой версии 2022 использовать доступные до обновления 2022.1 API групп параметров.

- Категории проверки выбираются отдельным компактным окном перед запуском, с собственным запоминаемым набором. Все окна используют рамку и стили SAB по примеру разверток. Корпуса — динамический список.
