# Область заливки из материала

Модуль основного плагина SAB для Autodesk Revit 2022–2024 создаёт и обновляет типы областей заливки по
штриховкам сечения материалов, которые фактически используются в активной модели.

## Поведение первой версии

- учитываются материалы геометрии элементов и материалы, нанесённые инструментом «Краска»;
- копируются передняя и фоновая штриховки сечения вместе с их цветами;
- имя типа формируется как `SAB_<имя материала>`;
- при повторном запуске существующие типы с префиксом `SAB_` обновляются;
- тип хранит связь с материалом и следует за ним при переименовании;
- устаревшие типы не удаляются и не изменяются;
- окно настроек делает снимок параметров материалов, типов и экземпляров областей заливки;
- можно настроить несколько соответствий параметров материала параметрам типа или экземпляра области заливки;
- настройки сохраняются внутри текущего проекта Revit;
- можно выбрать охват материалов, учёт покраски, префикс, переднюю и фоновую штриховки и цвета;
- штриховки и выбранные параметры обновляются при каждом запуске команды;
- окно использует общую визуальную систему SAB по образцу окна «Развёртки»;
- материалы без штриховки сечения пропускаются;
- связанные модели в первой версии не обрабатываются;
- ручные типы без префикса `SAB_` не изменяются.

## Установка

Модуль компилируется в единую `SAB.dll` и устанавливается штатным MSI SAB.
После установки перезапустить Revit. Команда находится на вкладке `SAB`,
панель `Альбом и графика`. Одна кнопка `Области заливки из материала`
с прежней иконкой создания открывает настройки. Кнопка `Создать / обновить`
сохраняет настройки и выполняет синхронизацию. `Сохранить` только сохраняет настройки.

Отдельных DLL и `.addin`-манифестов для модуля нет.
