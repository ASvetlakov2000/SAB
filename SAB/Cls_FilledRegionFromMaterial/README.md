# Область заливки из материала

Модуль основного плагина SAB для Autodesk Revit 2022–2024 создаёт и обновляет типы областей заливки по
штриховкам сечения материалов, которые пользователь включил в таблице всех материалов активного документа.

## Ручной выбор материалов1.1.3

Основная кнопка открывает четыре колонки: «В работу», «Материал», «Штриховка сечения», «Действие». Начальный набор пустой. Подсветка строк Shift/Ctrl служит пакетом для «Включить»/«Выключить»; переключатели определяют состав обработки. «Выделить все» и Ctrl+A работают только с видимыми строками, Space переключает пакет. Поиск по имени и «Все / Выбранные / Невыбранные» сохраняют скрытые включённые материалы. Класс материала не показывается.

Обычный текст чёрный даже в выделенной строке; «Создать» синий, «Обновить» зелёный, «Нет штриховки» красный. Имена передней/фоновой штриховок доступны полностью через tooltip. Отмена не открывает транзакцию. Подтверждение передаёт только включённые UniqueId существующей синхронизации.

## Сохранённое поведение

- каталог содержит все материалы документа, включая неиспользуемые и материалы покраски;
- копируются передняя и фоновая штриховки сечения вместе с их цветами;
- имя типа формируется как `SAB_<имя материала>`;
- при повторном запуске существующие типы с префиксом `SAB_` обновляются;
- тип хранит связь с материалом и следует за ним при переименовании;
- устаревшие типы не удаляются и не изменяются;
- окно настроек делает снимок параметров материалов, типов и экземпляров областей заливки;
- можно настроить несколько соответствий параметров материала параметрам типа или экземпляра области заливки;
- настройки сохраняются внутри текущего проекта Revit;
- можно выбрать префикс, переднюю и фоновую штриховки и цвета; прежние IncludeUnused/IncludePainted сохранены в схеме данных, но скрыты и не ограничивают ручной каталог;
- штриховки и выбранные параметры обновляются при каждом запуске команды;
- окно использует общую визуальную систему SAB по образцу окна «Развёртки»;
- материалы без штриховки сечения пропускаются при включённой настройке пропуска; если она выключена, tooltip сообщает о создании/обновлении типа без штриховки;
- связанные модели в первой версии не обрабатываются;
- ручные типы без префикса `SAB_` не изменяются.

## Установка

Модуль компилируется в единую `SAB.dll` и устанавливается штатным MSI SAB.
После установки перезапустить Revit. Команда находится на вкладке `SAB`,
панель `Альбом и графика`. Кнопка `Области заливки из материала`
с прежней иконкой открывает выбор материалов. `Настройки областей заливки` доступны отдельно;
кнопка `Выбрать материалы` сохраняет настройки и открывает тот же выбор. `Сохранить` только сохраняет настройки.

Отдельных DLL и `.addin`-манифестов для модуля нет.

Окно хранит detached DTO без объектов Revit. Compiled BAML загружает общий scoped SABFluentLight через FluentResourceDictionary. Actual WPF evidence вне Revit: Docs/Ui/DesignSystem/MaterialSelection-Report.json и screenshots-material-selection. Native Revit/model transactions, OS DPI и physical input — отдельные непроверенные границы.
