# SAB 1.1.3 — Выбор материалов для областей заливки

Следующее последовательное обновление после опубликованного1.1.2.

- Команда «Области заливки из материала» открывает таблицу всех материалов текущего документа. Пользователь сам включает материалы для обработки.
- Доступны поиск по имени, фильтры «Все / Выбранные / Невыбранные», Shift/Ctrl, выделение всех видимых строк и пакетное включение/выключение. Поиск сохраняет выбор, включая скрытые строки.
- Четыре колонки: «В работу», «Материал», «Штриховка сечения», «Действие». Обычный текст чёрный, «Создать» синий, «Обновить» зелёный, «Нет штриховки» красный.
- Подтверждение создаёт или обновляет типы только для включённых материалов. Сопоставления параметров и связь с существующими типами сохранены. Команда не размещает новые контуры на виде.
- Настройки доступны отдельной кнопкой; «Выбрать материалы» из настроек также открывает таблицу. Отсутствие штриховки обрабатывается согласно сохранённому флажку пропуска.

Сохраняются изменения предыдущих выпусков: параметризация, предпросмотр направлений, подсказки выбора развёрток и отдельное правило перехода с ошибочно пронумерованной1.1.4.

## Проверка

Фактическое WPF-окно SAB проверено вне Revit на демонстрационных данных:42 проверки и9 снимков, включая цвета выделенных строк, массовые операции, поиск, минимальный размер, подтверждение и отмену. Дистрибутивы пересобраны и проверены для Revit2022/2023/2024 с извлечением содержимого MSI, включая новое скомпилированное окно, DLL, инструкции и ссылки на API соответствующего года. Работа на живой модели Revit, физический ввод, переходы DPI и установка не проверялись.
