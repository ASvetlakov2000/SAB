## Установка

1. Полностью закройте Revit.
2. Скачайте `.msi` для своего года Revit и запустите его двойным щелчком.
3. Завершите установку и снова откройте Revit. На ленте появится вкладка **SAB**.

Права администратора не нужны. Плагин устанавливается только для текущего
пользователя Windows. Если работаете с несколькими версиями Revit, установите
пакет для каждого года. Revit 2025 и более новые версии этим выпуском не поддерживаются.

Для использования SAB не нужны Git, Visual Studio и исходники проекта.
Архивы **Source code**, автоматически добавленные GitHub, не являются установщиками.

## Что входит

- Единый плагин SAB с инструментами параметров, материалов, ведомостей, развёрток,
  видов, листов, графики и напоминанием о синхронизации.
- Семейства и зависимости для соответствующего года Revit.
- Локальный каталог и 22 инструкции: **SAB → Настройки → Инструкции**.
  Справка работает без интернета.

Для обновления закройте Revit и запустите новый MSI своего года.
Удаление — через список установленных приложений Windows, **SAB Revit <год>**.

## Проверка загрузки

В `SHA256SUMS.txt` опубликованы контрольные суммы SHA-256 всех установщиков.
В PowerShell можно вычислить сумму скачанного файла:

```powershell
Get-FileHash .\SAB_Revit_2023.msi -Algorithm SHA256
```

Установщики пока не подписаны цифровым сертификатом: Windows может предупредить
о неизвестном издателе. Перед запуском убедитесь, что файл скачан из репозитория
**ASvetlakov2000/SAB** и его контрольная сумма совпадает.
