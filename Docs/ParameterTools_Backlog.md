# Отложенные задачи

Зафиксировано по уточнению пользователя от 01.10.2026. Не входят в текущую версию.
Начинать только после отдельного прямого сообщения пользователя «работай по бэклогу» или равнозначного разрешения. Автоматически и по времени не запускать.

- [ ] Радиальное меню выбора трёх корпусов по боковой кнопке мыши.
  - Изучена механика SAB-Plus: GlobalInputHookService, OverlayController, RadialOverlayWindow.
  - Выбор удержанием и отпусканием, отмена в центре и по Escape.
  - Поддержка DPI, отсутствие захвата фокуса, работа только в проекте Revit.
  - Защита от повторного запуска и смены модели/вида/выделения до выполнения.
  - Развести триггеры с существующим колесом SAB+.
- [ ] Контуры корпусов и автоматическое определение зоны элемента.
  - Привязка контуров к уровням или всему проекту.
  - Полное попадание или строго больше 50% геометрии в одном корпусе.
  - Одинаковый алгоритм в заполнении и проверке.
  - Диагностика перекрывающихся контуров, границ и отсутствия большинства.
- [ ] Мягкая проверка геометрической принадлежности помещению.
  - Текущая ускоренная версия определяет помещение по штатным связям/контрольным точкам и сравнивает значения с этим источником.
  - При нескольких источниках элемент пропускается целиком. Разработать варианты выбора стороны/источника после обсуждения с пользователем.
- [ ] Вариативные режимы заполнения: ручное указание помещения, элементы на границах и несколько источников.
  - Ручной выбор после запуска является основным режимом; автоматическое определение уже доступно как настройка.
  - Отложено обсуждение нескольких источников и дополнительных правил выбора для неоднозначных элементов.
- [ ] Помещения из связанных моделей: документ связи, трансформация, фаза, диагностика выгруженной связи.
