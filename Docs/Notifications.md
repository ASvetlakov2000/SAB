# SAB — Уведомления

В ленте одна кнопка: **SAB → Настройки → Уведомления**. Она открывает единое окно.

- Тумблер немедленно включает/отключает обработку и сохраняет состояние. В выключенном состоянии нет перехвата, toast и новых записей от обработчика.
- Два независимых уровня: «Обычные уведомления» скрывает предупреждения без изменения модели; «Важные уведомления» разрешает исправления, рассоединение и удаление. Оба тумблера сохраняются и применяются сразу. Общий выключатель отключает оба уровня.
- Toast использует существующий `SabStyledToastHost` из решения SAB: карточки без заголовка окна, внизу справа, без захвата фокуса. Длительность по умолчанию 10 секунд, настраивается от 3 до 60. Одновременно видно не больше трёх карточек; все события записываются в журнал. Истечение времени удаляет карточку независимо от завершения анимации.
- В карточке полный текст сообщения, отдельное копируемое поле ID, «Откатить» и «Журнал». Undo разрешается только для последнего распознанного действия в активной модели, через ExternalEvent с повторной проверкой состояния.
- «Открыть журнал в браузере» открывает обычный HTML, «Показать папку журнала» открывает Проводник. Полный путь виден в окне. Файл `SAB-Уведомления-YYYY-MM-DD.html` хранится рядом с моделью/центральной моделью либо в выбранной папке для серверной модели. При недоступности папки используется `%LOCALAPPDATA%/RevitQuiet`. Новые записи видны после обновления страницы. Технический JSONL остаётся внутренней копией для диагностики.
- Открытие/закрытие обычных окон, диалог создания проекта и запрос сохранения не порождают toast и не запускают выбор папки. DialogBoxShowing обрабатывает только распознанное предупреждение удаления или явно заданное правило ответа.
- Для `Dialog_Revit_DocWarnDialog` читается текущая запись в журнале Revit: API не отдаёт текст базового диалога. Только свежее предупреждение «Помимо выбранных элементов будут удалены…» с `0 failures, 0 errors, 1 warnings` и включённым уровнем важных уведомлений запускает ограниченный обработчик штатной кнопки OK. OverrideResult(1) не используется: в этом диалоге он закрывал окно без выполнения удаления. Обработчик ищет новое видимое окно, принадлежащее главному окну Revit, с кнопками OK/Отмена/Показать/Развернуть, в течение 5 секунд; затем отправляет BM_CLICK только кнопке OK. Другой диалог и возврат к Idling отменяют поиск. Успешное удаление отмечается только по DocumentChanged, а не по отправке нажатия. Текст сначала сохраняется; фактически удалённые ID берутся из DocumentChanged. Старые завершённые диалоги и ошибки не подтверждаются. Если текущая запись ещё не доступна или отличается, штатный диалог остаётся открытым.

Исходники: `SAB/Notifications`. Запуск/остановка — `SAB.MainPanel`. Отдельный RevitQuiet.dll не требуется.

Сборки:

```
MSBuild.exe SAB/SAB.csproj /t:Build /p:Configuration=Release /p:PlatformTarget=x64 /p:RevitVersion=2023 /p:OutputPath=bin/Notifications2023/
MSBuild.exe SAB/SAB.csproj /t:Build /p:Configuration=Release /p:PlatformTarget=x64 /p:RevitVersion=2024 /p:OutputPath=bin/Notifications2024/
```

`Installer/Install-NotificationsLocal.ps1` обновляет существующие подключения SAB через новую папку, сохраняя прежние manifest в .bak. Изменения вступают в силу при следующем запуске Revit.

Проверки: `powershell -NoProfile -STA -File Tests/Notifications/Verify.ps1 -RevitVersion 2023` (или 2024). Проверяются реальный образец журнала предупреждения, отклонение устаревшей записи и ошибки, HTML-экранирование и добавление событий, исчезновение toast по таймеру. Обе версии скомпилированы. Живое подавление предупреждения после перезапуска Revit ещё требует проверки; момент сброса журнала на диск зависит от Revit.

Тест штатной кнопки: Tests/Notifications/NativeButton.ps1 создаёт собственный тестовый модальный диалог за пределами экрана и проверяет выполнение Click. Пройден для сборок 2023/2024. Этот тест не подменяет проверку удаления уровня в запущенном Revit.

Обновление 10.09: тёмная компактная карточка, полный текст ошибки в Expander, отсутствие пустого поля ID, исправленная кодировка крестика, иконка Icons8 Dreamstale 16/32px. Undo связывается с содержащей исходную операцию группой транзакций, кнопка обновляется на Idling; при недоступности показывает причину в подсказке. Tests/Notifications/CompactToast.ps1 проверяет размеры иконок, высоту и раскрытие карточки, привязку Undo к составной операции и отклонение старых/посторонних изменений. Работа Undo в реальной модели требует проверки после перезапуска.
