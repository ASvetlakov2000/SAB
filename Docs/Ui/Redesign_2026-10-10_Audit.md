# Перенос согласованных окон SAB · 10.10.2026

Пользователь разрешил перенос трёх согласованных макетов в рабочий SAB: развёртки,
создание видов и листов, параметризация. Revit 2022–2024, .NET Framework 4.8,
WPF-UI 4.3.0. Остальные модули не входят в этот перенос.

## Проверка устройства модулей перед переносом

| Модуль | Действующий механизм | Инвариант переноса |
| --- | --- | --- |

| Виды и листы | `Rows`, `InsertRowAfterCommand`, импорт/экспорт, Excel, группировка, перенос строк, несколько структур, окно подробных настроек | Команды и коллекции остаются прежними. Построчный плюс уже имеется. Панель настроек становится видимой; подробные настройки сохраняют отдельное окно |
| Параметризация | Клонирование профиля, нормализация и восстановление ссылок; отдельные команды сохранения, заполнения и проверки | Не меняются RuleEngine, Storage, Catalog, привязки параметров, категории записи и транзакции. Поле источника выбранного правила переносится в левую панель, привязка к `Rule.Source` сохраняется |

Предпросмотр развёрток — проекция выбранных контуров, не редактируемая очередь
создания. Ранее показывался первый пример. Теперь показываются все выбранные
контексты с тем же `ElevationNamingService`; это не добавляет контуры или виды.
Имена повторно проверяются при создании. Синтетические строки макета не используются
как новые сущности рабочего модуля.

Фильтр «Показать только выбранные категории» означает включённые тумблеры
`CategoryChoice.Selected`, а не подсветку строк ListBox. Поиск пересекается с этим
фильтром. Фильтрация не изменяет профиль и выбор; массовое отключение обновляет
представление после обработки всего выделения.

## Визуальное направление и критерии проверки

Источник: одобренный пользователем нативный макет `Tools/UiReview`, его PRODUCT,
DESIGN, DIRECTION и screenshots. Светлая рабочая поверхность #F7F8FA, белые панели,
Segoe UI, акцент #0F6CBD, серые контуры #D8DEE8, панели 8 DIP, поля 5 DIP,
левая колонка 320–340 DIP, разделение колонок 18 DIP, текстовый предпросмотр.
Иллюстраций листов и схем нет. Одна цветная скруглённая рамка ввода, отдельный
зазор прокрутки. Контур галочки и её отметка центрируются независимо от исходных
координат Path; пользователь отдельно попросил это исправить.

Использованы UI UX Pro Max, Impeccable, frontend-design и правила Nice3point
для сохранения границы Revit API. Текущий модальный механизм не переделывается
в модельный ради дизайна. Стили нового оформления подключены только к трём
модулям и их окнам выбора/подробных настроек.

Сохраняются короткие анимации SAB: появление окна, смена вкладок, раскрытие,
наведение, нажатие, обратная связь. Они используют SnapshotAndReplace, FillBehavior.Stop
и учитывают отключение анимаций Windows; геометрия layout не анимируется.

## Проверки и ограничения

`Tests/UI.Redesign` открывает реальные классы окон с тестовыми данными. Для
развёрток конструктор ViewModel обращается к документу Revit; вне Revit тест
инициализирует только его коллекции представления через reflection. Это **не**
проверка сбора данных модели или построения геометрии. Скриншоты сохраняются в
`outputs/redesign-live`; параметризация — `outputs/redesign-parameterization`.

`Tests/ParameterTools.Preview` проверяет существующие редакторы и новый фильтр,
включая поиск вместе с фильтром, массовое отключение и восстановление скрытых
категорий. `Tests/UI.Theme` проверяет загрузку XAML, фокус, рамки, прокрутку,
виртуализацию и уменьшенное движение. Проверки внутри установленного Revit
в этом протоколе не заявлены.

Итог проверки рабочих окон: PASS — реальные конструкторы окон, текстовый
предпросмотр выбранной строки, все контексты развёрток, вставка под строкой,
четыре вкладки развёрток при минимальном размере, две полные строки правил.
Галочка проверена геометрически в обычном масштабе и при 200%.
В ограниченном по высоте предпросмотре правила полный текст доступен прокруткой.

Повторный UI.Theme: PASS для обоих словарей (фокус, валидация, редактируемые
ComboBox и таблицы, виртуализация 2000 строк, зазоры, быстрые повторные анимации
и отключённое движение); загружаются 24 XAML-окна. Регрессии ядра: ParameterTools
91, запись 11, разрешение помещений 29 проверок с API doubles; раскладка листов
развёрток 31 336 утверждений. Эти проверки не заменяют запуск в модели Revit.

Независимый Impeccable finish reviewer проверил 11 обязательных снимков и после
исправлений дал **ship**. Исправлены доступ к правым столбцам и кнопкам при
минимальной ширине, высота редакторов формул, читаемость отключённой кнопки,
компактная таблица правил, клавиатурный фокус и обрезание GUID в предпросмотре.
Убраны декоративные Unicode-значки панелей. Переключение выбранной строки
обновляет текстовый предпросмотр короткой анимацией 170 мс / 2 DIP с учётом
отключения анимаций. Вызовов Revit API в анимациях нет.

Установщики выпуска 1.0.1 собираются после итогового коммита и публикуются как
GitHub Release assets, без добавления бинарных сборок в исходники Git.
