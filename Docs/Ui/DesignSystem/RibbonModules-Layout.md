# Панель SAB — группировка и цвета17.10.2026

Источник: прямой запрос пользователя17.10 и два приложенных снимка ленты. Разрешены изменения ribbon, без переработки окон/команд и без установки. Незакоммиченные материалы TemplateEditor не затрагиваются.

Поверхность — нативная Revit ribbon, поэтому WPF Layout Patterns окон неприменимы. Сохраняются существующие панели, подписи, command identities/availability/lifecycle. Владельцы: `SAB/Cls_MainPanel/MainPanel.cs`, общий загрузчик `SAB/Helpers/Ribbon/Ribbon.cs`, составные значки `SAB/Cls_ParameterTools/ParameterToolsIcons.cs`.

Схема: Настройки → Библиотека → Альбом и графика [Создать/Удалить виды и листы; Редактор шаблонов; Области заливки из материала ▼ {создание, настройки}] → Материалы и ведомости → Параметры → Развертки → Экспликации. Каркас регистрируется с прежними командами, но его панель скрыта. Две схемы сложного окна N/A: новых окон нет. Настройки заливки вторым пунктом; IsSynchronizedWithCurrentItem=false сохраняет создание основным действием после выбора настроек.

Палитра принадлежит общему ribbon-слою, не меняет WPF-токены окон. Перекраска сохраняет альфа-канал PNG и исходную геометрию, кроме белых внутренних прорезей заполненного значка Библиотеки: они превращаются в прозрачность со сглаживанием, сохраняя детали и один RGB128.16/32DIP и96DPI нормализация сохраняются. Новые изображения/пакеты не нужны. Для незаданных ресурсов сохраняются исходные цвета; прежний gray override скрытого Каркаса остаётся.

Проверка: целевые сборки2022/2023/2024 и штатные MSI, сравнение извлечённых DLL по SHA256; actual production icon loader/composite render16/32/48, цвета/альфа/размеры и неизменённые ресурсы; source review порядка/identity/скрытия панели. Native Revit ribbon/open popup/hover/keyboard/OS DPI — NOT RUN без фактического запуска в Revit; WPF contact sheet не выдаётся за Revit. Независимый read-only review по ReviewRoles после evidence; итог всех ID в RibbonModules-Report.json.
