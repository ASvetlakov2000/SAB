# Эталон: настройки параметров

Статус: тестовые концепции для одного согласования, 11.10.2026. Основа — SAB.ParameterTools.UI.SettingsWindow; существующее рабочее окно не изменяется.

Задача пользователя: задать получатели параметров и источники, проверить значения и область категорий, сохранить конфигурацию. Источники зависят от выбранного правила. Правило, параметр, источник и обязательность должны читаться в одной строке.

Сравнены две структуры. Master–Detail с вертикальным списком правил уменьшает ширину, но скрывает одновременное сравнение источников и обязательности. Tabbed Workspace с таблицей сохраняет сравнение правил и уже знакомые четыре раздела. Выбран второй вариант; детали источников находятся в своей вкладке, а не в постоянной правой панели.

```text
┌ SAB UI Preview · тестовые данные ─ раздел стенда ─ концепция ┐
│ Настройки параметров                                       │
│ Правила записи в модель · импорт / экспорт конфигурации     │
│ Правила | Источники | Значения и сопоставления | Категории   │
│                                                           │
│ Добавить правило · Удалить                                 │
│ Вкл.  Сущность  Заполняемый параметр  Источник  Настроить   │
│ …     …         имя + краткие метаданные       …            │
│                                                           │
├ сообщение проверки ───────── Сбросить демо · Сохранить ─────┤
```

Все три концепции и Unified используют одну структуру, одинаковые столбцы, данные и действия. Различия — поверхности, плотность, линии, радиусы и типографическая иерархия. Часть редакторов метаданных компактнее исходного production: GUID доступен в tooltip/выпадающем списке, тип и поведение в группах видны в строке. Это изменение представления явно относится к тестовой версии.

Нормальный размер окна с системной рамкой 1200×840 DIP; минимум 980×680. Захватывается клиентская область 1184×801 / 964×641 DIP на текущей системе. Сетка таблицы занимает остаток, подвал закреплён. Вложения таблиц ограничены по высоте и сохраняют собственную прокрутку. Длинные подписи переносятся; текст редактируемых значений прокручивается внутри поля, полные метаданные параметра доступны в tooltip. При нехватке ширины разрешена горизонтальная прокрутка таблицы; последний столбец действий остаётся доступным. Основной текст 13 DIP, вспомогательный 12 DIP, краткие метаданные внутри составной строки 11 DIP. Плотность не уменьшает основной текст.

Концепции: Fluent Light — просторнее и мягче; Fluent Compact — плотнее; Minimal SaaS — меньше рамок и более отчётливая иерархия; Unified — светлые поверхности, компактные поля и спокойные таблицы. Предлагается Unified как стандарт SAB.

Реальные состояния и переходы проверяются через общий Preview: редактирование/удаление/добавление правила, фильтрация параметров и категорий, выбор источника, Disabled, валидация, пустые данные и демонстрационная загрузка. Результат сохранения — только demo; никакой записи в Revit.
