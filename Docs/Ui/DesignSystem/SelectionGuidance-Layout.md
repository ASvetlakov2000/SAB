# Подсказки выбора линий16.10.2026

Прямой запрос пользователя во время завершения предыдущего обновления: сразу после «Выбрать линии» показать последовательность выбора линий → Escape → помещение; перед выбором помещения точный текст «Линии выбраны, выберите помещение». Сопровождать также повторные группы и выбор нескольких помещений. Выпуск окна1.1.1 уже опубликован; следующий последовательный выпуск этих подсказок1.1.2.

Pattern: существующая transient NotificationCard/NotificationStack, scoped SABFluentLight,416DIP/10активных секунд. Учебные подсказки явно разрешены в уведомлениях этим запросом; inline инструкции в рабочих окнах не добавляются. API-контекст/порядок PickObject, Escape и TaskDialog остаются прежними. DTO содержит только строки. Показ и закрытие собственной подсказки не должны прерывать выбор при ошибке UI.

Точки показа в общем TryPickLineGroupsAndRoom: overview до выбора режима; SingleGroup сразу выбирает линии без дублирующего старого toast; MultipleGroups показывает конкретный номер каждой группы, после валидного Escape напоминает добавить группу или завершить их выбор. Только после завершения всех групп/валидации линий показывается точное напоминание выбрать помещение; при завершении/отмене подсказка закрывается. Этот общий путь используется главной кнопкой и каждой строкой списка нескольких помещений.

Каждая новая подсказка заменяет только прежнюю подсказку данного workflow; остальные уведомления сохраняются. Общий API Dismiss(NotificationMessage) удаляет конкретную карточку по identity DTO. ShowActivated=false и существующий owner/time/close сохраняются; modeless timers/callbacks не вызывают Revit API. Footer «Инструкция» для transient guide N/A.
