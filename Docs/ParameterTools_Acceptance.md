### Запись, группы и диагностика — 09.10.2026

- [ ] Группа и вложенная группа на двух этажах: обработаны только выбранные экземпляры;
  при одновременном выделении члена и группы нет повторной записи.
- [ ] Источник «Уровень элемента»: этаж берётся из своего уровня / основы / уровня группы,
  а не из активного плана. В режиме уровня плана прежнее ограничение этажом сохраняется.
- [ ] Автоматические помещения разных этажей: номер, имя, корпус соответствуют своему
  помещению. Для неоднозначных элементов — причина, без случайного выбора помещения.
- [ ] Ручное помещение: одно помещение для всего выделения; выбор по умолчанию сохранён.
- [ ] Два одноимённых параметра с разными GUID: записан именно выбранный, второй не изменён.
- [ ] Параметр VariesAcrossGroups=false: пропущен в группах, одна сводная строка на GUID/ID,
  другой разрешённый параметр записан. Вне групп тот же параметр записывается штатно.
- [ ] Все параметры запрещены в группах: информативный отчёт без выбора лишнего помещения
  и без изменения модели. Сводка не вызывает ошибку на «Выделить» / «Показать».
- [ ] Расширение привязки: сохранены категории, GUID, прежние значения (в том числе отличающиеся
  у групп), VariesAcrossGroups; новые категории получают параметр.
- [ ] Ошибка одного параметра (только чтение, несовместимое число, нет источника): другие
  доступные записи сохраняются; в отчёте точный параметр, GUID/ID, значения и причина.
- [ ] Нативный отказ на Commit: исходное сообщение Revit, FailureDefinitionId, ID элементов;
  вся операция отменена, успешных записей 0, ложного списка применённых значений нет.
- [ ] Группы с различными источниками: нет записи индивидуального Extensible Storage
  в членов группы; остальные экземпляры не изменяются побочно.
- [ ] Отчёт сохранён по указанному пути, «Копировать отчёт» содержит подробности и версию Revit.
- [ ] «Отменить» Revit отменяет всю успешную операцию одной командой.

Автоматическая WPF-проверка дополнена выбором одноимённых параметров по GUID,
переходом к источнику выбранной строки, четырьмя разделами инструкции, минимальным
размером настроек, сводкой без ElementId и полным текстом технических подробностей.
Снимки: `outputs/parameter-write-groups/preview`. Это проверка вне Revit.
