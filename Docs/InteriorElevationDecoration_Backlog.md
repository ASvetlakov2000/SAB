# Оформление разверток — задачник

Обновлено: 2026-09-28.

## Ближайшее расширение категорий

- Получить от пользователя перечень дополнительных категорий элементов.
- Добавить полученные категории в каталог оформления и в выбор состава создаваемых марок.
- Для каждой новой категории поддержать элементы основной модели и связанных файлов.
- После проверки маркировки использовать тот же каталог категорий как основу для образмеривания.
- Получить от пользователя отдельные правила образмеривания каждой добавленной категории и реализовывать их только после согласования.

Статус входных данных: ожидаются два набора информации от пользователя:

1. Перечень новых категорий для маркировки.
2. Правила образмеривания этих категорий.

## Настройки размещения марок

- Сохранить существующий индивидуальный выбор типа марки и режима «с выноской / без выноски» для каждой категории.
- Добавить для каждой категории настройку ориентации марки относительно элемента:
  - сверху;
  - справа;
  - слева;
  - снизу.
- Применять ориентацию при первичном вычислении точки вставки, без последующего хаотичного перемещения марки.
- Сохранять выбранную ориентацию в настройках между запусками.
- При проверке попадания марки в границы вида корректировать только проблемную марку, сохраняя выбранную сторону настолько, насколько позволяет область вида.

## Порядок работ

1. Получить и добавить категории маркировки.
2. Добавить для них типы марок, выноски и стороны размещения.
3. Проверить маркировку на основной модели и связях.
4. Получить правила образмеривания.
5. Добавить размеры по тем же категориям.
