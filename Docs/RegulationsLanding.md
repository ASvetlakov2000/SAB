# Лендинг регламентов

Кнопка «Регламенты» открывает единый HTML с разделами «Наименования» и «BIM Советы». Стрелка кнопки раскрывает пункт «Изменить путь к лендингу»: в стандартном окне выбора можно выбрать HTML/HTM или вставить полный путь в поле имени файла.

Пользовательская настройка хранится в `%APPDATA%/SAB/Regulations/landing-path.txt`, отдельно от DLL, и общая для версий Revit этого пользователя. При отсутствии настройки используется `G:\Общие диски\Ideologist Архитектурный\Софт\Плагины для Revit\SAB\Инструкции\Стандарты_HTML\01_IDEOLOGIST_HTML_Reglamenty.html`.

Пустой, недоступный или неверный путь вызывает предложение выбрать другой файл. После выбора новый путь сохраняется и документ открывается. При ошибке браузера также предлагается переопределение. Отмена не изменяет настройку. Ручная смена из меню сохраняет путь без автоматического открытия браузера. При недоступности сетевого диска можно отменить выбор и восстановить подключение — путь останется прежним.

Существующие страницы разделов и их ссылки не меняются. Автоматического поиска одноимённых файлов в подкаталогах нет.

PNG получены с сервиса Icons8 непосредственно в размерах 16×16 и 32×32, цвет 6B7B88, прозрачный фон:
- https://img.icons8.com/material-outlined/16/6B7B88/edit-folder.png
- https://img.icons8.com/material-outlined/32/6B7B88/edit-folder.png

Файлы встроены как EmbeddedResource; интернет во время работы не нужен. 32×32 подключён к LargeImage, 16×16 — к Image, согласно [рекомендациям Autodesk для ленты](https://help.autodesk.com/cloudhelp/2017/ENU/Revit-API/files/GUID-1547E521-59BD-4819-A989-F5A238B9F2B3.htm).
