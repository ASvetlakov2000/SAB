# Архив открытия регламентов

Прежние команды регламентов находятся в `SAB/Archive` и не подключены к текущей ленте.
Сетевые пути организаций удалены. Архивное значение по умолчанию указывает на локальный
каталог инструкций рядом с SAB.dll; имена HTML используют только префикс `SAB_HTML_`.

Действующая справка: **SAB → Настройки → Инструкции**. Её устанавливает MSI в
`%APPDATA%\Autodesk\Revit\Addins\<год>\SAB\Docs\PluginInstructions`.
Открытие выполняет `SAB/Instructions/InstructionLauncher.cs`.
Содержание и правила подготовки: `Docs/PluginInstructions/README.md`.
