# Кнопка инструкций и первая инструкция — 09.10.2026

## Реализовано

- SAB → Настройки → Инструкции: общая HTML-страница. Команда доступна без открытой модели
  через отдельную проверку доступности, не изменяет модель.
- Кнопка «Инструкция» в настройках параметров открывает первую инструкцию напрямую.
- Открытие через приложение по умолчанию для .html в Windows, без сервера и интернета.
- Локальные файлы рядом с установленным SAB.dll в Docs/PluginInstructions.
- Неизменённый CSS универсального пользовательского шаблона; контрольная сумма SHA256
  `78FFAF94AF5FE1DBDE191E97895D8ABB0C3943F48277F9C4AEA3D771FF176E1A`.
- Короткий рабочий маршрут, отдельные закрытые сценарии, ошибки и пробная проверка
  на 2–3 элементах. Без описания внутреннего кода и Revit API.
- Предыдущие HTML сохранены, в новом каталоге только первая актуализированная инструкция.
- Новая команда использует Nice3point.Revit.Toolkit для соответствующего года Revit.

## Выполненные проверки

- Восстановление всех трёх закреплённых версий Toolkit из packages.config.
- Сборки SAB и MSI для Revit 2022, 2023, 2024.
- 6 проверок разрешения пути: установленный каталог, прямая ссылка на параметры,
  исходный checkout, отсутствие HTML/CSS, неподдерживаемое имя.
- Браузер Edge: каталог и инструкция на 1440 и 390 px, локальные ссылки и якоря,
  отсутствие горизонтального переполнения и шаблонных полей; раскрытие сценария клавиатурой.
- Визуальная проверка первого экрана, каталога, списка сценариев, ручного сценария и ошибок.
- WPF-проверки настроек, включая наличие кнопки «Инструкция», без старого окна справки.
- Чтение таблицы File каждого MSI: каталог, инструкция параметров, template.css и Toolkit DLL
  присутствуют во всех трёх установщиках.

Снимки и журнал сборки: outputs/instructions (не включаются в Git).

## Проверка пользователем в Revit

Нативный запуск ещё не проверен. Закрыть Revit, установить сборку своего года и запустить Revit.
Нажать SAB → Настройки → Инструкции; открыть первую инструкцию и раскрыть свой сценарий.
Проверить также кнопку «Инструкция» в настройках параметров. HTML должен открываться
в браузере по умолчанию, включая работу без интернета.

Инструкции остальных инструментов SAB не разрабатываются до отдельной команды пользователя.
