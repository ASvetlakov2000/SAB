# Локальные инструкции SAB — 09.10.2026

## Реализовано

- Общий вход: SAB → Настройки → Инструкции. Доступен без открытой модели.
- Из настроек параметров «Инструкция» открывает соответствующее руководство напрямую.
- В каталоге 22 инструкции по инструментам восьми панелей SAB; описаны все 20 операций библиотеки.
- Для каждого инструмента: подготовка, запуск, действия, результат, пробная проверка и причины ошибок.
  Варианты применения вынесены в закрытые раскрывающиеся сценарии.
- Сохранён согласованный дизайн. Контрольная сумма SHA256 assets/template.css:
  `78FFAF94AF5FE1DBDE191E97895D8ABB0C3943F48277F9C4AEA3D771FF176E1A`.
- Наименования файлов, заголовки, ссылки и настройки используют только SAB.
  Привязка к прежней организации и её сетевым путям удалена, в том числе из архивных исходников.
- Убраны прежние шаблоны и регламент организации из поставляемой справки.
  Отсутствующие в текущей ленте команды не представлены как доступные инструменты.
- HTML и локальные ресурсы устанавливаются вместе с плагином; интернет не требуется.
- Tools/Build-UserGuides.py воспроизводит каталог и 21 руководство. Одобренное руководство
  параметров поддерживается отдельно. Метаданные библиотеки читаются из её действующего окна.

## Проверка в Revit

Нативный запуск после этих изменений не проверен. Закройте Revit, установите MSI своего года
и запустите Revit. Откройте SAB → Настройки → Инструкции, выберите руководство и раскройте
сценарий. Проверьте также «Инструкция» в настройках параметров и чтение без интернета.
Рабочие сценарии новых руководств сверены с исходниками; их результаты на реальной модели
нужно проверить небольшим пробным запуском соответствующего инструмента.
