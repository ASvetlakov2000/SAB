Все кнопки находятся в панели Развертки.

1) Создать развертки по линии

Описание команды: команда Создать развертки по линии строит фасады по выбранным линиям, поддерживает работу с одной или несколькими группами линий и сквозную нумерацию.

Режим 1: По одной группе линий

  1. Выберите режим «По одной группе линий».
  2. Выберите линии группы.
  3. Выберите помещение.
  4. Проверьте настройки и нажмите «Создать развертки».

Режим 2: По нескольким группам линий

  1. Выберите режим «По нескольким группам линий».
  2. После каждой группы нажимайте «Выбрать следующую группу линий».
  3. После завершения нажмите «Завершить выбор групп».
  4. Выберите помещение и запустите построение.
Нумерация углов и видов идет сквозная по всем группам текущего помещения.
[Скриншот] Окно создания разверток с параметрами.

2) Разворот развертки 180

Описание команды: команда Разворот развертки 180 создает корректный зеркальный вариант фасада относительно выбранной линии.

  • Выберите фасад на плане этажа.
  • Выберите линию, по которой создавался фасад.
  • Команда создает корректный повернутый вариант и сохраняет настройки вида.
  • При размещении на листе вид сохраняет позицию в рабочем сценарии команды.
[Видео] Исправление неверного направления развертки.

3) Перенос видов на след. лист

Описание команды: команда Перенос видов на след. лист переносит/копирует нужные виды на новый лист и сохраняет логику размещения.

  • Команда переносит вьюпорты разверток на новый лист.
  • Для план-схемы используется копирование с детализацией.
  • Проверяйте итоговую компоновку листа после переноса.
[Скриншот] Лист до и после переноса видов.

4) Выровнять марки углов

Описание команды: команда Выровнять марки углов корректирует положение марок углов после создания и переноса разверток.

  • Команда выравнивает марки углов на плане.
  • Используется как финальный этап после создания/переноса разверток.
[Скриншот] Выравнивание марок углов до/после.
Для панели «Помещения» используйте отдельный раздел на главной странице: «Проверка геометрии помещений».
