HTML просмотр

Кнопка находится в панели Библиотека.

1) Что делает команда

Описание команды: открывает CSV-источник в отдельном HTML viewer и автоматически выбирает профиль отображения по имени файла.

  • Поддерживает только CSV.
  • Профили: Системные семейства, Загружаемые семейства, Линии, Штриховки.
  • Для линий и штриховок отображаются миниатюры из PNG-папок.

2) Как пользоваться

Запуск

  1. Нажмите HTML просмотр.
  2. Нажмите Выбрать источник и укажите CSV.
  3. Проверьте выбранный профиль по имени файла.
  4. Нажмите Открыть.

Проверка профиля по имени файла

  • Если имя содержит Системные семейства_ → профиль системных.
  • Если имя содержит Загружаемые семейства_ → профиль загружаемых.
  • Для линий и штриховок используйте соответствующие CSV-имена экспорта.
[Скриншот] Окно выбора CSV-источника для viewer.
Если миниатюры не отображаются, сначала проверьте, что PNG уже выгружены и лежат в ожидаемых папках рядом с CSV-набором.
