Как открыть и начать.

  1. В Revit откройте SAB → Настройки → Инструкции. Выберите инструмент в разделе его панели.
  2. Прочитайте подготовку и порядок работы. Для сложного инструмента раскройте свой сценарий.
  3. Сначала проверьте инструмент на небольшом наборе данных. Сравните результат по пунктам инструкции, затем выполняйте основную работу.
  4. Кнопка Инструкция в настройках параметров открывает сразу руководство по заполнению параметров.

Локальная справка.

Интернет не требуется. HTML и оформление устанавливаются вместе с SAB и открываются в браузере по умолчанию Windows. Кнопка инструкций доступна без открытой модели.

Файлы: %APPDATA%\Autodesk\Revit\Addins\<год>\SAB\Docs\PluginInstructions.

Для обновления справки установите новую сборку SAB для своего года Revit.

Если справка не открылась.

Проверьте приложение по умолчанию для .html в Windows. Если файлов нет, повторно установите SAB. Не переносите HTML отдельно от папки assets.
