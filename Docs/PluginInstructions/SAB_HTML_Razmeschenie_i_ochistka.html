Размещение и очистка библиотеки.

Разместите образцы из CSV или удалите выбранные библиотечные данные.

Порядок работыЕсли не получилось

Перед началом.

Сохраните копию модели. Для размещения нужен CSV подходящей категории и хотя бы один уровень в модели.

Удаление может затронуть связанные типы, семейства, линии и штриховки. Проверяйте состав перед подтверждением.

Порядок работы.

  1. Откройте модель, с которой будете работать. Для изменения данных сначала сохраните её копию.
  2. Нажмите SAB → Библиотека → Библиотека.
  3. Раскройте ниже нужный сценарий. Выберите указанный режим и карточку операции; затем нажмите «Запустить».
  4. Выполните запросы выбора файла, папки или элементов. Дождитесь результата и прочитайте сообщения о пропусках.
  5. Проверьте созданные файлы или изменённые элементы по пунктам «Проверка результата».

Выберите свой сценарий.

Раскройте только нужный раздел.

Размещение по точке

Создаёт экземпляры точечных семейств из библиотечного CSV. Перед запуском: подготовить CSV и убедиться, что в проекте есть уровень.

  1. Подготовьте CSV нужной категории.
  2. В окне «Библиотека» выберите «Размещение и очистка», затем карточку «По точке». Нажмите «Запустить».
  3. Выберите файл.
  4. Проверьте размещённые экземпляры и созданный итоговый вид.
Размещение по линии

Создаёт линейные экземпляры семейств из библиотечного CSV. Перед запуском: подготовить CSV и убедиться, что в проекте есть уровень.

  1. Подготовьте CSV линейной категории.
  2. В окне «Библиотека» выберите «Размещение и очистка», затем карточку «По линии». Нажмите «Запустить».
  3. Выберите файл.
  4. Проверьте элементы, размещённые вдоль линии.
Размещение по границе

Создаёт элементы по замкнутому контуру из библиотечного CSV. Перед запуском: подготовить CSV и убедиться, что в проекте есть уровень.

  1. Подготовьте CSV категории с контуром.
  2. В окне «Библиотека» выберите «Размещение и очистка», затем карточку «По границе». Нажмите «Запустить».
  3. Выберите файл.
  4. Проверьте созданные элементы и их границы.
Удалить выбранные типы и семейства

Удаляет выбранные экземпляры и связанные типы, семейства, линии или штриховки. Перед запуском: выбрать элементы и проверить зависимости перед подтверждением.

  1. Выберите только нужные экземпляры или образцы.
  2. Учтите связанные типы, семейства, линии и штриховки.
  3. В окне «Библиотека» выберите «Размещение и очистка», затем карточку «Удалить выбранное». Нажмите «Запустить».
  4. Подтвердите удаление и проверьте итоговые ошибки.

Проверка результата.

  1. Начните с небольшого CSV и проверьте созданные элементы, уровень и итоговый вид.
  2. Для удаления сначала выделите один ненужный образец на копии модели. После операции проверьте оставшиеся типы и семейства.

Если не получилось.
