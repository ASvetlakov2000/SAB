Загружаемые семейства и миниатюры.

Получите CSV-каталог семейств и PNG для просмотра библиотеки.

Порядок работыЕсли не получилось

Перед началом.

Загрузите нужные семейства в модель. Выберите доступную для записи папку.

Для одного каталога используйте согласованные выгрузки CSV и PNG из той же модели.

Порядок работы.

  1. Откройте модель, с которой будете работать. Для изменения данных сначала сохраните её копию.
  2. Нажмите SAB → Библиотека → Библиотека.
  3. Раскройте ниже нужный сценарий. Выберите указанный режим и карточку операции; затем нажмите Запустить.
  4. Выполните запросы выбора файла, папки или элементов. Дождитесь результата и прочитайте сообщения о пропусках.
  5. Проверьте созданные файлы или изменённые элементы по пунктам Проверка результата.

Выберите свой сценарий.

Раскройте только нужный раздел.

Экспорт загружаемых семейств

Создаёт CSV-каталоги загружаемых семейств и типоразмеров. Перед запуском: открыть проект и выбрать папку экспорта.

  1. Откройте модель с нужными семействами.
  2. В окне Библиотека выберите Каталоги, затем карточку Загружаемые семейства. Нажмите Запустить.
  3. Выберите папку результата.
  4. Проверьте CSV в ctg_loadable families.
PNG загружаемых семейств

Выгружает изображения предпросмотра загружаемых семейств. Перед запуском: открыть проект и выбрать папку экспорта.

  1. Выгрузите CSV загружаемых семейств.
  2. В окне Библиотека выберите Каталоги, затем карточку PNG семейств. Нажмите Запустить.
  3. Выберите папку для изображений.
  4. Проверьте, что имена PNG соответствуют строкам CSV.

Проверка результата.

  1. Откройте CSV из ctg_loadable families и проверьте несколько семейств и типоразмеров.
  2. Откройте несколько PNG и проверьте соответствие имён строкам CSV.
