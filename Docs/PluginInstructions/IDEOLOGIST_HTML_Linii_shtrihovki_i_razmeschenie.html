Описание Экспорт CSV PNG-образцы

Описание плагина

Линии и штриховки.

Команды выгружают стили линий и штриховки, создают образцы на видах и экспортируют PNG для HTML-просмотра.

Эта страница относится к модулю Библиотека. Сначала выгружаются CSV, затем при необходимости размещаются образцы в Revit и экспортируются PNG-превью.

Для полноценного HTML-просмотра образцов нужно выполнить не только CSV-экспорт, но и экспорт PNG линий или штриховок.

Библиотека: Системные Загружаемые Линии и штриховки Типы Материалы HTML просмотр

Команды 01

Экспорт CSV.

CSV содержит параметры стилей линий и штриховок, которые нужны для проверки и HTML viewer.

  1. Для линий нажмите Экспорт линий.
  2. Для штриховок нажмите Экспорт штриховок.
  3. Результат сохраняется в папку ctg_lines-patterns.
  4. Откройте CSV и проверьте имена, цвета, веса линий и параметры штриховок.

Команды 02

Размещение и PNG-образцы.

Команды создают наглядные образцы, которые затем попадают в HTML viewer.

Линии

  • Размещение линий создает образцы линий на виде.
  • Экспорт PNG линий экспортирует изображения образцов.
  • HTML viewer показывает цвет и PNG-превью, если файлы уже созданы.

Штриховки

  • Размещение штриховок размещает образцы заполненных областей.
  • Экспорт PNG штриховок сохраняет изображения штриховок.
  • Перед экспортом проверьте, что вид с образцами существует и читается.
