Библиотека

Линии, штриховки и размещение

Инструкция по экспорту CSV линий и штриховок, размещению элементов на видах и созданию PNG-превью для HTML viewer.

Экспорт CSV Размещение элементов по CSV Дополнительные способы размещения

Сценарий 01

Экспорт CSV

CSV является исходной таблицей для размещения элементов и последующего просмотра.

Линии

  1. Нажмите Экспорт линий.
  2. Выберите рабочую папку.
  3. Проверьте файл в ctg_lines-patterns.

Колонки: Наименование, Миниатюра, Категория, Вес линии, Цвет, Образец.

Штриховки

  1. Нажмите Экспорт штриховок.
  2. Выберите рабочую папку.
  3. Проверьте файл в ctg_lines-patterns.

Колонки: Наименование, Миниатюра, Штриховка переднего плана, Штриховка заднего плана, Маскирование, Тип штриховки.

Сценарий 02

Размещение элементов по CSV

Размещение создает элементы на активном виде строго по строкам выбранного CSV.

Размещение линий

  1. Откройте чертежный вид для размещения.
  2. Нажмите Размещение линий.
  3. Выберите CSV линий.
  4. Проверьте, что размещены все строки таблицы.

Размещение штриховок

  1. Откройте вид для размещения.
  2. Нажмите Размещение штриховок.
  3. Выберите CSV штриховок.
  4. Проверьте итоговый набор размещенных штриховок.
Важно: экспорт PNG запускайте только после корректного размещения элементов на виде.

Сценарий 03

Дополнительные способы размещения

Эти команды относятся к блоку размещения и помогают вставлять элементы по точке, границе, линии или подготовить легенд-компоненты.

Размещение по точке

  1. Откройте целевой вид.
  2. Выберите CSV.
  3. Укажите точки вставки по сценарию команды.

Размещение по границе

  1. Откройте вид с целевыми границами.
  2. Выберите CSV.
  3. Запустите размещение вдоль выбранной границы.

Размещение по линии

  1. Откройте вид с линиями привязки.
  2. Выберите CSV.
  3. Запустите размещение вдоль линии.

Расставить комп. легенды

  1. Откройте активный вид Легенда.
  2. Запустите команду.
  3. После расстановки используйте нужный экспорт PNG.

Сценарий 04

Экспорт PNG превью

PNG создаются для уже размещенных элементов. Если размещения нет или активный вид неверный, часть изображений может не появиться.

Экспорт PNG линий

  • Команда: Экспорт PNG линий.
  • Сначала выполните Размещение линий.
  • Источник: активный чертежный вид с размещенными линиями.
  • Папка результата: ctg_lines-patterns\PNG_Lines.

Экспорт PNG штриховок

  • Команда: Экспорт PNG штриховок.
  • Сначала выполните Размещение штриховок.
  • Источник: вид Библиотека_Штриховки.
  • Папка результата: ctg_lines-patterns\PNG_Fills.
Если PNG не создались: проверьте активный вид, наличие размещенных элементов и проблемные символы в именах файлов.

Сценарий 05

Удаление элементов

Команда удаляет выбранные типы и семейства по сценарию очистки библиотеки.

  1. Выберите элементы или типы для удаления по рабочему сценарию.
  2. Нажмите Удаление элементов.
  3. Проверьте отчет или уведомление о результате удаления.
Перед удалением: сохраните модель или работайте в копии, если операция массовая.
