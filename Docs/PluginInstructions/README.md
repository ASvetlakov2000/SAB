# Локальные инструкции SAB

Общий вход: **SAB → Настройки → Инструкции**. Открывает
`IDEOLOGIST_HTML_Instruktsii.html` в приложении по умолчанию для HTML в Windows.
Кнопка доступна без открытой модели. В настройках параметров кнопка «Инструкция»
открывает `IDEOLOGIST_HTML_Zapolnenie_parametrov.html` напрямую.

Установка: `%APPDATA%\Autodesk\Revit\Addins\<год>\SAB\Docs\PluginInstructions`.
HTML и локальные ресурсы включает MSI; отсутствие стартовой страницы, первой инструкции
или CSS прерывает сборку установщика. Интернет для чтения не нужен.

Оформление: неизменённый `assets/template.css` из пользовательского комплекта
`Universal_HTML_Template_Kit`, версия комплекта 1.1. Используются его навигация,
первый экран, разделы, шаги, таблицы и карточки. Сценарии открываются стандартными
HTML-разделами details/summary, без JavaScript и внешних библиотек.

Редакционные правила пользователя:

- Аудитория: начальный и средний уровень Revit. Без объяснений кода и Revit API.
- Основной маршрут: подготовка → открытие → настройки → действия → результат → пробная проверка.
- Названия кнопок, полей, вкладок и категорий сверять с русским интерфейсом.
- Варианты применения описывать отдельно, в коротких раскрывающихся сценариях.
- Указывать необходимые условия, причины ошибок и конкретные действия для проверки.
- До проверки пользователем подготовить только кнопку, каталог и первую инструкцию.
  Инструкции остальных инструментов SAB начинать только по отдельной команде пользователя,
  после передачи сборки с кнопкой и первой инструкцией. Сама проверка не является командой начать.

Прежние HTML-документы сохранены рядом для справки; в новом каталоге пока показана
только первая актуализированная инструкция. Прежнее окно WPF-инструкции параметров
заменено ссылкой на локальный HTML.

Проверки: `Tests/Instructions` — разрешение путей и браузерные проверки страниц на
ширинах 1440 и 390 px. Проверка запуска команды внутри Revit выполняется отдельно.
