# Локальные инструкции SAB

Общий вход: **SAB → Настройки → Инструкции**. Открывает `SAB_HTML_Instruktsii.html`
в браузере по умолчанию Windows, в том числе без открытой модели.
Кнопка «Инструкция» в настройках параметров открывает руководство параметров напрямую.

Каталог содержит **22 инструкции** по действующим инструментам всех восьми панелей SAB.
Сценарии 20 операций окна «Библиотека» сгруппированы по назначению. Старые шаблоны,
регламент организации и руководство отдельной отсутствующей кнопки выравнивания марок
убраны из поставляемой справки. Работу с марками описывают актуальные инструкции
«Границы видов» и «Оформление разверток».

Установка: `%APPDATA%\Autodesk\Revit\Addins\<год>\SAB\Docs\PluginInstructions`.
MSI включает весь каталог и локальные ресурсы. Интернет для чтения не нужен.
Файлы называются `SAB_HTML_*.html`. Название плагина — только **SAB**.
Инструкции не связаны с работодателями и сторонними организациями.

Оформление: неизменённый `assets/template.css` из `Universal_HTML_Template_Kit`, версия 1.1.
После него все страницы подключают `assets/compact.css`: компактные поля, заголовки,
шаги и таблицы, две колонки каталога от 1000 px. Основной текст — 17 px.
Вложенные шаги не получают отдельную рамку, названия кнопок остаются внутри предложений.
Сценарии открываются через стандартные HTML details/summary, без скриптов и внешних ресурсов.
Инструкция параметров сохранена в согласованном виде, переименован её файл и ссылки.

Правила текста:

- Начальный и средний уровень Revit; без объяснений кода и Revit API.
- Подготовка → запуск → настройки → действия → результат → пробная проверка.
- Названия кнопок, полей и категорий сверять с действующим русским интерфейсом.
- Варианты применения помещать в отдельные короткие раскрывающиеся сценарии.
- Описывать условия, последствия, причины ошибок и конкретные действия для проверки.

Пересоздание каталога и 21 руководства: `python Tools/Build-UserGuides.py`.
Руководство параметров редактируется отдельно; генератор его не перезаписывает.
Тексты операций библиотеки и подписи карточек генератор читает из исходников её окна.
Изменения интерфейса требуют редакторской проверки соответствующих инструкций.

Проверки: `Tests/Instructions` — разрешение путей, все страницы на 1440 и 390 px,
локальные ссылки и якоря, состав каталога, покрытие операций библиотеки, клавиатура,
закрытые сценарии и контрольная сумма утверждённого CSS.
Проверяется также раскрытие всех сценариев без переполнения и уменьшение высоты страниц
относительно того же содержимого без compact.css. Результаты: outputs/instructions/density.json.
Запуск кнопок и реальные результаты внутри Revit проверяются отдельно.
