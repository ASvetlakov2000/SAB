Сценарий 01

Экспорт имен типов

Команда формирует XLSX-наборы для системных, загружаемых и прочих категорий, чтобы переименование выполнялось по отдельным группам.

  1. Откройте модель Revit.
  2. На ленте SAB откройте Библиотека.
  3. Нажмите Экспорт имен типов.
  4. Выберите рабочую папку.
  5. Откройте папку name и проверьте XLSX-файлы.

Системные семейства

Содержат столбец Структура для справочной проверки слоев.

Загружаемые семейства

Используются для переименования семейств и типоразмеров.

Прочее

Отдельная группа для категорий, которые не попали в первые два набора.

Сценарий 02

Правка XLSX перед импортом

Редактируйте только целевые значения и флаги удаления. Названия столбцов и общий формат файла менять нельзя.

КолонкаЧто заполнять
КатегорияНе менять. Это категория типа.
Старое семействоНе менять без необходимости. Это исходное имя семейства.
Новое семействоНовое имя семейства, если его нужно изменить.
Старый типоразмерНе менять. Это исходное имя типа.
Новый типоразмерНовое имя типа.
СтруктураСправочная информация для системных типов.
Удалить1 - удалить тип, 0 - оставить.
Правило безопасности: не совмещайте массовое переименование и массовое удаление в первом проходе, если таблица еще не проверена.

Сценарий 03

Импорт: команда «Переименовать типы»

Команда применяет изменения построчно. Проблемные строки попадают в отдельный отчет, а обработка остальных строк продолжается.

  1. Нажмите Переименовать типы.
  2. Выберите подготовленный XLSX-файл.
  3. Дождитесь итогового уведомления.
  4. Проверьте несколько измененных типов в диспетчере проекта.
  5. Если создан отчет Проблемные наименования.csv, откройте его и исправьте строки.
