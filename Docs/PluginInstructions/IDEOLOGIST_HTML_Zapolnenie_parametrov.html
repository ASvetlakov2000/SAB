Заполнение параметров.

Перенесите корпус, этаж и данные помещения в выбранные элементы. Или задайте собственные значения.

Подготовка

Что нужно для работы.

  • Открытая модель в Revit 2022, 2023 или 2024 с установленным SAB.
  • Параметры, в которые будете записывать значения, уже есть у нужных элементов и доступны для изменения.
  • Если копируете данные из помещения, нужные значения сначала заполнены в самом помещении.
Начните с 2–3 элементов. Проверьте результат на небольшом выделении. После этого заполняйте остальные элементы.

Порядок работы

Открыть → настроить → заполнить → проверить.

Пример: перенос номера и имени помещения в выделенные элементы.

  1. Откройте настройки. На вкладке SAB, в панели Параметры нажмите стрелку рядом с кнопкой Занести параметры и выберите Настройки параметров.
  2. Задайте, что заполнять. Во вкладке Правила выберите Заполняемый параметр и источник Из помещения. Для другого параметра нажмите Добавить правило. Оставьте включёнными только нужные правила.
  3. Задайте, откуда брать значение. Во вкладке Источники под надписью «Выберите правило, для которого настраиваете источник» выберите правило и настройте номер, имя или параметр помещения. Повторите для остальных правил. В поле Как выбираем помещение оставьте Выбрать вручную после команды.
  4. Выберите категории и сохраните. Во вкладке Категории отметьте, например, «Стены», «Мебель» или «Сантехнические приборы» — те категории, которые будете заполнять. Нажмите Сохранить настройки. Значения в элементы пока не записываются.
  5. Заполните выделение. Выделите элементы одного помещения или нужную группу. Нажмите Занести параметры, затем укажите помещение или его марку. На 3D-виде выберите помещение из списка.
  6. Проверьте результат. Посмотрите итоговое уведомление. Выберите один обработанный элемент и проверьте значения на палитре Свойства. Если появился отчёт, прочитайте причины пропусков. Ошибочную операцию можно отменить кнопкой Отменить или сочетанием Ctrl+Z в Revit.
Одно выбранное помещение — на всё выделение. В ручном режиме все подходящие элементы получат данные указанного помещения. Для другого помещения выполните заполнение отдельно.

Настройка под вашу задачу

Откройте нужный сценарий.

Для каждого заполняемого параметра можно выбрать свой источник. После настройки сценария сохраните настройки и выполните шаги «Заполните выделение» и «Проверьте результат» выше.

Как устроено окно настроек и как искать параметры
ВкладкаЧто здесь делать
ПравилаВыбрать заполняемый параметр и источник. «Проверять» отмечает параметр как обязательный для проверки заполненности.
ИсточникиВыбрать данные помещения или элемента, способ получения уровня и список корпусов.
Значения и сопоставленияВвести постоянные значения, варианты ручного выбора, таблицы замены значений и значения для уровней.
КатегорииУказать, какие категории элементов заполнять и нужно ли обрабатывать элементы внутри групп.

В поле параметра введите часть названия и выберите строку из найденных. Сам ввод текста не меняет выбранный параметр. Escape отменяет поиск.

Название выделено синим. Зелёная подпись означает, что параметр может отличаться в разных экземплярах групп; красная — не может. Если имена одинаковые, сравните GUID/ID — уникальный идентификатор параметра. Если не знаете нужный идентификатор, уточните его у BIM-координатора.

Взять номер, имя или другой параметр из помещения
  1. В «Правилах» выберите заполняемый параметр и источник Из помещения.
  2. В «Источниках» выберите Номер помещения, Имя помещения или Параметр помещения. В последнем случае дополнительно выберите нужный параметр помещения.
  3. Сохраните настройки. Выделите элементы, запустите заполнение и вручную укажите помещение.

Пример: корпус заранее записан в помещении. Выберите его параметр как источник для целевого параметра корпуса у элементов. Таким же способом переносятся другие сведения из помещения.

Всегда записывать одно значение в этой модели
  1. В «Правилах» выберите нужный параметр и источник Постоянное значение.
  2. Во вкладке Значения и сопоставления введите, например, «Корпус 3», 0 или 1.
  3. Сохраните настройки. При заполнении выбранные элементы будут получать это значение.

Значение хранится в настройках этой модели. Если корпус изменился, замените значение один раз и сохраните настройки. Ранее заполненные элементы изменятся только после повторного заполнения.

Перед каждой записью вручную выбирать корпус, этаж или другое значение
  1. Для любого параметра выберите источник Выбрать перед записью.
  2. Во вкладке Значения и сопоставления составьте список, например «1 этаж», «2 этаж», «3 этаж».
  3. Сохраните настройки, выделите элементы и запустите заполнение. В появившемся окне выберите значение для текущего выделения.

Для корпуса есть готовый вариант: источник Корпус вручную. В «Источниках» заполните список Корпуса для ручного выбора. При запуске заполнения выберите нужный корпус.

Последний выбор запоминается. Если отменить выбор, запись не начнётся. Если все правила используют только ручные или постоянные значения, выбирать помещение не нужно.

Заполнять этаж по уровню элемента
  1. Выберите источник Из модели: уровень.
  2. В «Источниках», в поле Откуда брать уровень, выберите Уровень элемента.
  3. Во вкладке Значения и сопоставления, в таблице Уровни → значения, укажите значение для каждого нужного уровня. Например, для уровня «6-19» — «6-19 этаж».

Для нескольких этажей используйте «Уровень элемента». Вариант «Уровень текущего плана» ограничивает заполнение этажом открытого плана. Если уровень не определяется, используйте сценарий ручного выбора значения.

Копировать значение из другого параметра того же элемента
  1. Выберите целевой параметр и источник Из модели: параметр.
  2. В «Источниках» выберите Исходный параметр этого элемента.
  3. Сохраните настройки и заполните выделение. Проверьте, что исходный и целевой параметры совместимы: текст копируется в текст, число — в подходящий числовой параметр.
Заменять исходные значения по своей таблице
  1. Выберите источник По таблице сопоставления.
  2. Во вкладке Значения и сопоставления укажите, что сравнивать: название уровня элемента, параметр элемента, номер, имя или параметр помещения.
  3. Добавьте пары: исходное значение → нужное значение. Например, «6-19 → 6-19 этаж». Сохраните настройки.

Совпадение должно быть однозначным. Если нужной строки нет или исходное значение повторяется в таблице, параметр будет пропущен с объяснением. Для источника из помещения при заполнении также нужно указать помещение.

Заполнять элементы групп, скопированных по этажам
  1. В «Категориях» включите обработку элементов внутри выделенных групп, включая вложенные, и отметьте категории их элементов.
  2. Настройте источники: для этажа — уровень элемента или ручной выбор; для данных помещения — источник из помещения; для корпуса — подходящий вам вариант.
  3. Выделите нужную группу и запустите заполнение. В ручном режиме укажите одно помещение для всех подходящих элементов выделения.
  4. Проверьте результат и список пропущенных параметров в отчёте.

Параметры, которые не могут отличаться между экземплярами групп, пропускаются. В отчёте каждый такой параметр указан один раз с причиной. SAB не разгруппировывает элементы и не меняет это свойство параметра.

Если группы относятся к разным помещениям, заполняйте их отдельно. Копирование самих групп выполняйте средствами Revit.

Определять помещение автоматически — дополнительный режим

Используйте, если нужно обработать элементы разных помещений за один запуск. Для начала надёжнее указать помещение вручную.

  1. В «Источниках», в поле Как выбираем помещение, выберите Определить автоматически.
  2. Для дверей и окон выберите нужную сторону помещения. Для стен, перекрытий, потолков и крыш нужен расчёт объёмов помещений. Если он выключен, попросите BIM-координатора проверить настройку модели.
  3. Выполните пробное заполнение на нескольких элементах. Проверьте, что данные взяты из нужного помещения, особенно у общих стен, дверей и перекрытий.

Если помещение не найдено или подходят несколько помещений, запись пропускается с причиной. Выделите спорные элементы отдельно и повторите заполнение с ручным выбором помещения.

Помещения связанных моделей пока не поддерживаются. Для размеров и других аннотаций используйте ручной выбор. Автоматический режим требует проверки на вашей модели.

Передать настройки коллеге или перенести в другую модель
  1. В настройках нажмите Экспорт конфигурации…. Сохраните файл JSON и передайте коллеге.
  2. В другой модели откройте настройки и нажмите Импорт конфигурации…. Выберите полученный файл.
  3. Прочитайте сообщение импорта. Проверьте параметры, уровни, категории, постоянные значения и корпуса: в другой модели они могут отличаться.
  4. Выберите недостающие параметры и нажмите Сохранить настройки. До сохранения можно нажать «Отмена» и оставить прежние настройки модели.

Импорт не создаёт отсутствующие параметры. Если нужного параметра нет, обратитесь к BIM-координатору. После переноса настроек сначала проверьте заполнение на 2–3 элементах.

Проверка результата

Как убедиться, что всё работает.

  1. Выберите 2–3 элемента. Запомните исходное значение одного параметра и выполните заполнение по своему сценарию.
  2. Прочитайте уведомление: сколько элементов обработано, сколько записей выполнено и какие параметры заполнены.
  3. На палитре «Свойства» проверьте новое значение. Для данных помещения сравните его с источником. Для групп дополнительно проверьте другой экземпляр группы.
  4. Если результат верный, продолжайте на остальных элементах. Если неверный — отмените операцию, исправьте источник или настройку и повторите пробу.
Отдельно: найти незаполненные обязательные параметры

В «Правилах» отметьте Проверять у нужных параметров. Запустите Проверить параметры и выберите категории текущего вида. Элементы с пустыми обязательными параметрами подсветятся красным.

После заполнения подсветка этих элементов исчезнет автоматически. Ноль считается заполненным значением. Снять подсветку убирает подсветку проверки SAB с текущего вида.

Эта команда ищет только пустые значения. Уже заполненное, но неправильное значение она не определяет. Проверка относится к выбранным категориям текущего вида, а не только к выделению.

Если не получилось

Что проверить по сообщению.

Сообщение или ситуацияЧто сделать
Нет подходящих элементовПроверьте выделение и категории. Для группы включите обработку её элементов. При работе на нескольких этажах выберите «Уровень элемента».
Параметр отсутствует или недоступен для измененияПроверьте параметр в свойствах элемента. Если имя повторяется, уточните нужный GUID/ID. Если вручную изменить нельзя, проверьте права редактирования или обратитесь к BIM-координатору.
Источник не определёнПроверьте выбранное помещение, заполненность исходного параметра, уровень и строку сопоставления. Помещение должно относиться к фазе текущего вида. Для спорного элемента выберите помещение вручную.
Параметр не изменяется в группахОстальные параметры могут быть заполнены. Для пропущенного параметра уточните у BIM-координатора, разрешены ли разные значения между экземплярами групп.
Значение несовместимо с типом параметраДля числового параметра вводите число. Поддерживаются текст, целое число, «Число» и «Денежная единица». Размерные значения, например длина или площадь, этим инструментом не записываются.
Revit отменил операцию или итоговое значение отличаетсяПрочитайте подробности отчёта. При полной отмене ничего не записано. При ошибке отдельного параметра остальные записи могли сохраниться — проверьте уведомление и свойства элементов.

Как передать ошибку на проверку

Выберите проблемную строку отчёта и нажмите Копировать отчёт. Передайте текст вместе с версией Revit и описанием: что выделили, какой источник выбрали и какое значение ожидали. Технические подробности нужны специалисту — самостоятельно разбирать их не требуется.

Если подсветка проверки не включается, проверьте, не управляет ли фильтрами шаблон вида. При необходимости обратитесь к BIM-координатору.
