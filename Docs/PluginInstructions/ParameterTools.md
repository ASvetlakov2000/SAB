# Заполнение и проверка параметров

Модуль встроен в SAB.dll для Revit 2022–2024.

## Настройка и заполнение

Открыть **SAB → Параметры → Занести параметры ▼ → Настройки параметров**.
Во вкладке «Правила» сопоставить сущности с параметрами экземпляров, выбрать источник
и включить «Проверять» для обязательных параметров. Остальные вкладки: «Источники»,
«Матрица уровней», «Категории».

| Источник | Значение |
| --- | --- |
| Из помещения | Номер, имя или выбранный параметр помещения |
| Из модели: уровень | Номер этажа из матрицы уровней |
| Из модели: параметр | Значение выбранного параметра элемента |
| Задать значение | Постоянное значение, в том числе числовой ноль |
| Корпус вручную | Значение из списка корпусов |

Для заполнения выделить элементы, запустить «Занести параметры» и выбрать помещение.
Ручной выбор является режимом по умолчанию. На 3D помещение выбирается из списка;
при неопределённом уровне заполнение предлагает заполненные строки матрицы уровней.
Автоматическое определение помещения включается отдельно в настройках.

«Выбрать корпус» находится во вкладке «Источники» при источнике «Корпус вручную».
Кнопка сохраняет настройки и назначает корпус выделенным элементам.
Галочка добавления параметров категориям расширяет существующие привязки без потери
прежних категорий, GUID и значений. Новые определения не создаются. Проверка привязки не меняет.

## Инструкция в окне и выбор параметров

Кнопка **«Инструкция»** внизу настроек открывает отдельное справочное окно:
начало работы, группы по этажам, выбор параметров, ошибки и отчёт. Выберите строку
правила и нажмите **«Настроить источник»**, чтобы открыть источник именно этой строки.
Название правила — подпись; логику определяют выбранный источник и его настройки.
«Сохранить настройки» сохраняет профиль; запись выполняется командой «Занести параметры».

У параметра показаны GUID (для общего параметра) или ID (без GUID), тип данных Revit
и признак изменения значений между экземплярами групп. Одноимённые параметры различаются
по идентификатору; запись по одному лишь имени не выполняется. Для неизвестного определения
показано «В группах: не определено». Перед записью используется фактическое определение модели.

## Группы, скопированные на этажи

1. В «Категориях» включите **«Обрабатывать элементы внутри выделенных групп, включая вложенные»**
   и отметьте категории членов групп. Эта опция включена по умолчанию, в том числе в старых профилях.
2. Для этажа задайте источник **«Из модели: уровень»**, в «Источниках» — **«Уровень элемента»**,
   затем заполните матрицу уровней. «Уровень текущего плана» оставляет ограничение этажом открытого плана.
3. Для номера / имени помещения выберите соответствующие поля источника «Из помещения».
   Для корпуса используйте параметр корпуса помещения, константу либо ручной выбор корпуса.
4. Для обработки разных помещений за один запуск включите автоматическое определение помещения.
   Ручной режим использует одно выбранное помещение для всего выделения.
5. Сохраните настройки, выделите экземпляры групп и выполните «Занести параметры».

Выделенные группы раскрываются на членов, включая вложенные группы. При одновременном
выделении группы и её члена элемент обрабатывается один раз. Собственный уровень элемента
имеет приоритет; если его нет, используется уровень основы или группы. Выбор уровня вручную,
когда автоматическое определение невозможно, общий для неразрешённых элементов операции.

Параметры, не допускающие разных значений между экземплярами групп, пропускаются только
у членов групп. В отчёте — **одна строка на параметр с GUID/ID и причиной**, без перечня помещений.
Остальные доступные параметры продолжают обрабатываться. SAB не разгруппировывает модель
и не меняет настройку изменения параметра по группам. Расширение привязок сохраняет этот признак.

Автоматическое определение не выбирает произвольно одно из нескольких помещений: такой
параметр получает причину отказа. Для неоднозначных стен / дверей выделите элементы одного
помещения и повторите запись в ручном режиме. Команда копирует сведения существующих
помещений и не перенумеровывает сами помещения.

Служебные сведения SAB об источнике не записываются непосредственно в членов групп:
индивидуальный Extensible Storage может нарушить согласованность экземпляров группы.
Для заполнения и текущей проверки заполненности эти сведения в членах групп не требуются.

## Диагностика отказов записи

Ошибка отдельного параметра не блокирует другие доступные записи. Отчёт показывает
параметр с GUID/ID и типом данных, текущее / ожидаемое значение, исходный текст исключения,
ID группы и технические подробности. В рабочей модели дополнительно читается владелец элемента.
Недоступный параметр, несовместимый тип и источник без значения объясняются отдельно.

При завершении транзакции собираются исходные сообщения Revit: описание, уровень ошибки,
FailureDefinitionId, ID проблемных и связанных элементов. Если Revit отменяет всю транзакцию,
отчёт явно сообщает, что **ничего не сохранено**, а счётчики успешных записей сбрасываются.
Никакие элементы для разрешения ошибок автоматически не удаляются.

Выберите строку отчёта для полного текста и нажмите **«Копировать отчёт»** для передачи
диагностики. Отчёт автоматически сохраняется в `%LOCALAPPDATA%\SAB\ParameterTools\report-*.txt`;
точный путь указан в окне. Общие исключения команд пишутся в `errors.log` в той же папке
и доступны в развёрнутых подробностях диалога. Если сохранение файла недоступно, текст
остаётся в окне и доступен для копирования. Сводные строки без элемента не меняют выделение.

Типы записи: текст, целое число, «Число», «Денежная единица». Размерные параметры
и ссылки на элементы отклоняются с причиной; автоматическое преобразование единиц не выполняется.

## Динамическая проверка заполненности

«Проверить параметры» открывает выбор категорий текущего вида. Набор запоминается
отдельно от категорий заполнения. Выделение не ограничивает фильтр: проверка и подсветка
охватывают выбранные категории текущего вида.

Для каждой категории создаётся ParameterFilterElement со стеком включённых обязательных
параметров. Условие: хотя бы один параметр не имеет значения; для текстовых проектных
параметров также проверяется пустая строка. Числовой ноль является заполненным значением.
Проверка не сравнивает значение с расчётным источником и не требует сохранённого помещения.

Имя: `SAB_Param_<Категория>_Пусто-<Параметр1>-ИЛИ-<Параметр2>_<идентификатор стека>`.
Длинные имена сокращаются; идентификатор различает стеки и параметры с одинаковыми именами.
Повторный запуск использует тот же фильтр без дубликатов. Предыдущие фильтры проверки
снимаются только с текущего вида; на других видах сохраняются.

Красная графика задана фильтром. После заполнения всех обязательных параметров элемент
автоматически перестаёт подходить под фильтр. Если параметр очистить, подсветка возвращается.
Фильтры сохраняются в модели и работают средствами Revit без повторного запуска команды.

Параметры должны быть доступны для фильтра категории. При отсутствии привязки команда
сообщает, какой параметр и категория требуют исправления. Если фильтрами управляет шаблон,
отключить управление фильтрами в шаблоне или включить временные свойства вида.
Шаблон команда не изменяет.

«Снять подсветку» снимает только помеченные модулем SAB фильтры с текущего вида.
Определения остаются в проекте для повторного использования. Пользовательские фильтры,
включая фильтры с похожим именем, не удаляются и не перезаписываются.
Кнопка доступна также в отчёте. Отчёт фиксирует состояние на момент проверки;
для обновления списка после ручного редактирования повторить проверку.

Старые прямые переопределения восстанавливаются по сохранённому снимку. При отсутствии
снимка очищается только узнаваемая графика старой версии. Сохранение и закрытие снимают
только старую подсветку; новые фильтры сохраняются.

## Архив

Вкладка «Условия», формулы, отдельные области правил и команда «Пробный расчёт» удалены
из рабочего интерфейса. Исходники и прежняя документация сохранены в
`SAB/Archive/ParameterToolsAdvanced`. При загрузке старого профиля расширенные настройки
переносятся в `ArchivedAdvancedRules`; заполнение использует источник напрямую.
Архив записывается в модель при следующем сохранении профиля.

Команды заполнения, проверки, снятия подсветки, выбора корпуса и настроек доступны
для штатных горячих клавиш Revit. Отложенные возможности из задачника не включены.
