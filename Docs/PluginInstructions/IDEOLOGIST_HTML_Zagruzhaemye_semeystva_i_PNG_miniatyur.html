Загружаемые семейства и PNG миниатюр

Экспорт загружаемых семейств, создание миниатюр и подготовка таблиц для дальнейшей работы.

Описание Экспорт PNG миниатюры

Описание плагина

Загружаемые семейства.

Страница описывает экспорт загружаемых семейств, создание PNG-миниатюр и подготовку данных для переименования или размещения.

Рабочий процесс такой же, как у всего модуля Библиотека: выгрузить категории из Revit, проверить и отредактировать таблицы в Excel или LibreOffice, затем использовать CSV для просмотра, переименования, удаления или размещения элементов.

PNG-миниатюры нужны для наглядной проверки в HTML viewer. Если миниатюры не экспортированы, таблица откроется, но изображений в строках не будет.

Библиотека: Системные Загружаемые Линии и штриховки Типы Материалы HTML просмотр

Команда 01

Экспорт загружаемых.

Команда собирает типы загружаемых семейств и сохраняет CSV по категориям.

  1. Откройте проект Revit с нужными загружаемыми семействами.
  2. На панели Библиотека нажмите Экспорт загружаемых.
  3. Выберите папку результата.
  4. Откройте папку ctg_loadable families.
  5. Проверьте CSV по категориям: категория, семейство, типоразмер, путь к миниатюре и служебные поля.

Команда 02

Экспорт PNG семейств.

Команда формирует PNG-миниатюры для загружаемых семейств, чтобы HTML viewer показывал карточки визуально.

  1. Нажмите Экспорт PNG семейств.
  2. Выберите папку для изображений.
  3. После экспорта проверьте, что имена PNG соответствуют строкам CSV.
  4. Откройте CSV через HTML просмотр и проверьте колонку Миниатюра.

Команды 03

Размещение и удаление.

CSV можно использовать как управляющую таблицу для размещения элементов в проекте и удаления лишних типов.

Размещение

  • Размещение по точке размещает экземпляры в выбранной точке.
  • Размещение по линии раскладывает элементы вдоль линии.
  • Размещение по границе использует контур или границу размещения.

Удаление

  • Удаление элементов удаляет выбранные типы или семейства.
  • Перед удалением проверьте выборку и зависимости в модели.
  • После операции смотрите итоговое уведомление и ошибки, если они есть.
