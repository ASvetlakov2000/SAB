Библиотека

Загружаемые семейства и PNG миниатюр

Инструкция по выгрузке CSV для загружаемых семейств, созданию PNG-миниатюр и открытию результата в HTML viewer.

Когда использовать Экспорт CSV загружаемых семейств Экспорт PNG миниатюр

Сценарий 01

Когда использовать

Сценарий нужен для каталогизации загружаемых семейств: мебели, оборудования, аннотаций, профилей и других RFA-семейств в проекте.

Команда выгружает

  • Категорию семейства.
  • Имя семейства.
  • Имя типоразмера.
  • Путь к миниатюре.
  • Служебный флаг Включить.

Рабочие папки

  • ctg_loadable families для CSV.
  • PNG_Family для изображений.

Сценарий 02

Экспорт CSV загружаемых семейств

CSV нужен для просмотра библиотеки и последующей работы с семействами по категориям.

  1. Откройте проект Revit с нужными загружаемыми семействами.
  2. На ленте SAB откройте Библиотека.
  3. Нажмите Экспорт загружаемых.
  4. Выберите рабочую папку.
  5. Проверьте общий CSV и CSV по категориям в ctg_loadable families.
Для начинающих: загружаемые семейства - это элементы, которые обычно загружаются в проект как отдельные RFA-файлы, в отличие от стен, перекрытий и потолков.

Сценарий 03

Экспорт PNG миниатюр

Миниатюры помогают быстрее проверять библиотеку в HTML viewer и визуально отличать типы.

Шаги

  1. Нажмите Экспорт PNG семейств.
  2. Выберите папку результата.
  3. Проверьте подпапку PNG_Family.

Как viewer ищет PNG

  • Основной ключ: Типоразмер.
  • Запасной ключ: Семейство_Типоразмер.
  • Если PNG добавлены позже, повторите экспорт CSV.

Сценарий 04

Открытие в HTML просмотре

Viewer автоматически выбирает профиль по имени CSV и показывает таблицу с миниатюрами, семействами и типоразмерами.

  1. Нажмите HTML просмотр.
  2. Выберите CSV, в имени которого есть Загружаемые семейства.
  3. Нажмите Открыть.
  4. Проверьте, что миниатюры отображаются рядом с типоразмерами.
Если миниатюры пустые: проверьте, что PNG лежат рядом с CSV-набором в ожидаемой папке и что имена файлов совпадают с типами.
