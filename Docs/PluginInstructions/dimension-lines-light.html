Все кнопки находятся на панели Библиотека.

1) Экспорт CSV

Описание команды: команды Экспорт линий и Экспорт штриховок формируют исходные таблицы для размещения и предпросмотра в viewer.

Линии

Команда: Экспорт линий

  • Файл сохраняется в ctg_lines-patterns.
  • Колонки: Наименование, Миниатюра, Категория, Вес линии, Цвет, Образец.

Штриховки

Команда: Экспорт штриховок

  • Файл сохраняется в ctg_lines-patterns.
  • Колонки: Наименование, Миниатюра, Штриховка переднего плана, Штриховка заднего плана, Маскирование, Тип штриховки.
[Скриншот] CSV линий и CSV штриховок.

2) Размещение элементов по CSV

Описание команды: команды Размещение линий и Размещение штриховок создают элементы на активном виде строго по строкам выбранного CSV.

Команда «Размещение линий»

  1. Откройте вид для размещения.
  2. Выберите CSV линий.
  3. Проверьте, что размещены все строки таблицы.

Команда «Размещение штриховок»

  1. Откройте вид для размещения.
  2. Выберите CSV штриховок.
  3. Проверьте итоговый набор размещенных штриховок.
Сценарий PNG-превью запускайте только после корректного размещения.

3) Экспорт PNG превью

Описание команды: команды Экспорт PNG линий и Экспорт PNG штриховок последовательно экспортируют изображения для каждого размещенного элемента.

Экспорт PNG линий

  • Команда: Экспорт PNG линий.
  • Источник: активный чертежный вид с размещенными линиями.
  • Папка результата: ctg_lines-patterns\PNG_Lines.

Экспорт PNG штриховок

  • Команда: Экспорт PNG штриховок.
  • Источник: вид «Библиотека_Штриховки».
  • Папка результата: ctg_lines-patterns\PNG_Fills.
Если часть PNG не создалась, проверьте активный вид, размещение элементов и проблемные имена файлов.
[Видео] Размещение + PNG экспорт для линий и штриховок.

4) Просмотр в HTML

Описание команды: команда HTML просмотр открывает профильные таблицы «Линии» и «Штриховки» с миниатюрами и параметрами оформления.

  • Команда: HTML просмотр.
  • Профиль определяется по имени CSV: «Линии» или «Штриховки».
  • В режиме линий миниатюра выводится рядом с наименованием и цветом.
[Скриншот] Viewer для профиля «Линии» и «Штриховки».
Рекомендуемый порядок: Экспорт CSV → Размещение → Экспорт PNG → HTML просмотр.
