Все кнопки находятся на панели Библиотека.

1) Экспорт CSV загружаемых

Описание команды: команда Экспорт загружаемых формирует таблицы только для загружаемых семейств и подготавливает данные для HTML-просмотра и последующей расстановки.

Команда

Экспорт загружаемых

  1. Выберите рабочую папку.
  2. Проверьте создание папки ctg_loadable families.
  3. Проверьте CSV по категориям и общий CSV.

Формат CSV

ВключитьСлужебный флаг
[Скриншот] CSV загружаемых семейств.

2) Экспорт PNG миниатюр

Описание команды: команда Экспорт PNG семейств сохраняет миниатюры типоразмеров в PNG, чтобы viewer подхватывал изображения напрямую из папки.

Команда

Экспорт PNG семейств

  1. Выберите папку.
  2. Проверьте подпапку PNG_Family.
  3. Проверьте имена PNG (они должны совпадать с именами типов).

Подхват миниатюр в CSV

  • Первичный ключ: Типоразмер.
  • Fallback: Семейство_Типоразмер.
  • Если PNG добавлены позже — повторите экспорт CSV.
[Видео] Экспорт PNG_Family и повторный экспорт CSV.

3) Открытие в HTML просмотре

Описание команды: команда HTML просмотр открывает отдельный профиль для загружаемых семейств и выводит таблицу с миниатюрами, семействами и типоразмерами.

  • Команда: HTML просмотр (панель Библиотека).
  • Профиль выбирается автоматически по имени CSV.
  • Для этого раздела в имени файла должна быть фраза «Загружаемые семейства».
В viewer колонка «Включить» скрыта, но в CSV сохраняется для служебной логики.
[Скриншот] Профиль «Загружаемые семейства» в viewer.
Рекомендуемый порядок: Экспорт PNG семейств → Экспорт загружаемых → HTML просмотр.
