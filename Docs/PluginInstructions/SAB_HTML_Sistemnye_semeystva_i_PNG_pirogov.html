Системные семейства и изображения типов.

Выгрузите каталог системных типов и подготовьте изображения слоёв для библиотеки.

Порядок работыЕсли не получилось

Перед началом.

В модели должны быть нужные типы стен, перекрытий, потолков или крыш. Подготовьте папку результата.

Для компонентов и изображений откройте вид «Легенда». Имена PNG должны соответствовать именам типов.

Порядок работы.

  1. Откройте модель, с которой будете работать. Для изменения данных сначала сохраните её копию.
  2. Нажмите SAB → Библиотека → Библиотека.
  3. Раскройте ниже нужный сценарий. Выберите указанный режим и карточку операции; затем нажмите «Запустить».
  4. Выполните запросы выбора файла, папки или элементов. Дождитесь результата и прочитайте сообщения о пропусках.
  5. Проверьте созданные файлы или изменённые элементы по пунктам «Проверка результата».

Выберите свой сценарий.

Раскройте только нужный раздел.

Экспорт системных семейств

Создаёт CSV-каталоги системных типов по категориям. Перед запуском: открыть проект и выбрать папку экспорта.

  1. Откройте модель с нужными системными типами.
  2. В окне «Библиотека» выберите «Каталоги», затем карточку «Системные семейства». Нажмите «Запустить».
  3. Выберите корневую папку библиотеки.
  4. Проверьте CSV в ctg_system families.
Разместить компоненты легенды

Расставляет компоненты системных типов по поддерживаемым категориям. Перед запуском: открыть активный вид типа «Легенда».

  1. Откройте вид «Легенда».
  2. В окне «Библиотека» выберите «Графика и превью», затем карточку «1 Компоненты». Нажмите «Запустить».
  3. Запустите размещение компонентов.
  4. Проверьте, что компоненты читаются и не перекрываются.
Экспорт PNG системных типов

Выгружает изображения компонентов легенды для системных типов. Перед запуском: открыть заполненный вид типа «Легенда» и выбрать папку.

  1. Откройте подготовленную легенду.
  2. В окне «Библиотека» выберите «Графика и превью», затем карточку «2 Экспорт PNG». Нажмите «Запустить».
  3. Выберите корневую папку библиотеки.
  4. Проверьте PNG_Pirogi: имена файлов должны совпадать с типами.
Загрузить изображения системных типов

Назначает подготовленные PNG параметру изображения типоразмера. Перед запуском: подготовить папку PNG с именами, совпадающими с типами.

  1. Сначала синхронизируйте имена типов и PNG.
  2. В окне «Библиотека» выберите «Графика и превью», затем карточку «3 Загрузка PNG». Нажмите «Запустить».
  3. Выберите папку PNG_Pirogi.
  4. Проверьте итог и параметр Изображение типоразмера.

Проверка результата.

  1. Откройте один CSV из ctg_system families и сравните имя типа с моделью.
  2. Откройте несколько PNG из PNG_Pirogi. После загрузки изображений проверьте «Изображение типоразмера» в свойствах типа.
