2) Дополнительные вкладки

HTML просмотр

Описание: открывает CSV в профильном HTML viewer (системные, загружаемые, линии, штриховки).

  • Источник данных: только CSV.
  • Профиль определяется по имени файла.
  • Отдельная инструкция: вкладка «HTML просмотр».

Стандарты Наименования

Описание: открывает нормативный HTML-документ по правилам именования.

  • Используется как справочник перед переименованием.
  • Не изменяет данные модели напрямую.
  • Отдельная инструкция: вкладка «Стандарты Наименования».

3) Проверка геометрии помещений

Описание: вкладка «Проверка геометрии помещений» содержит отдельную инструкцию по запуску Room Geometry Tools и сценариям проверки/построения осей.

  • Открыть инструкцию: Проверка геометрии помещений.
  • Панель в Revit: Помещения.
  • Команда: Проверка геометрии помещений.
Если названия кнопок в Revit изменятся, сначала обновляйте эту главную страницу, затем профильные вкладки.
