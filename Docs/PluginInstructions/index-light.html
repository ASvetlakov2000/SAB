Как читать этот комплект инструкций

Каждая вкладка соответствует конкретной кнопке (или группе кнопок) из ленты Revit. Здесь нет смешения сценариев между разными модулями.

Версия: Revit 2023/2024 Источник: команды из MainPanel Форматы: CSV / XLSX / PNG / HTML

2) Кнопка «HTML просмотр»

Где находится

Панель Библиотека → кнопка HTML просмотр.

  • Источник данных: только CSV.
  • Профиль определяется по имени файла.
  • Поддерживаемые профили: Системные семейства, Загружаемые семейства, Линии, Штриховки.

Перед запуском

  • Проверьте, что CSV выгружен нужной кнопкой.
  • Проверьте, что имя CSV соответствует профилю.
  • При необходимости заранее выгрузите PNG для миниатюр.
[Скриншот] Окно «Источник данных dashboard».

3) Кнопка «Стандарты Наименования»

Панель Регламент → кнопка Стандарты Наименования открывает HTML-документ с регламентом.

Используйте этот раздел как вход в нормативный документ, а рабочие сценарии обработки данных берите из вкладок этой инструкции.
[Скриншот] Открытый документ стандарта наименований.

4) Кнопка «Проверка геометрии помещений»

Панель Помещения → кнопка Проверка геометрии помещений открывает отдельное окно Room Geometry Tools.

  • Проверка углов помещений.
  • Проверка неразмещенных помещений.
  • Проверка изменения площади.
  • Построение осей помещений.
[Скриншот] Окно Room Geometry Tools.
Если названия кнопок в Revit изменятся, сначала обновляйте эту главную страницу, затем профильные вкладки.
