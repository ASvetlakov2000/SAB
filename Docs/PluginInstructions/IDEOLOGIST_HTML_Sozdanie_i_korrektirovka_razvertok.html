Создание и корректировка разверток

Инструкция по созданию разверток по линиям, развороту вида на 180 градусов и выравниванию марок углов.

Перед созданием разверток Создать развертки по линии Разворот развертки 180

Сценарий 01

Перед созданием разверток

Подготовьте линии и помещение на плане. Чем чище исходные линии, тем меньше корректировок потребуется после создания видов.

  • Откройте план помещения, для которого нужны развертки.
  • Проверьте, что линии разверток лежат в нужном месте и имеют понятное направление.
  • Проверьте, что помещение размещено и корректно ограничено.
  • Если нужно переносить готовые виды на лист, после создания откройте инструкцию Листы.

Сценарий 02

Создать развертки по линии

Команда строит фасады по выбранным линиям. Можно работать с одной группой линий или с несколькими группами для одного помещения.

Режим: одна группа линий

  1. Нажмите Создать развертки по линии.
  2. Выберите режим По одной группе линий.
  3. Выберите линии группы.
  4. Выберите помещение.
  5. Проверьте настройки и нажмите Создать развертки.

Режим: несколько групп линий

  1. Выберите режим По нескольким группам линий.
  2. После каждой группы нажимайте Выбрать следующую группу линий.
  3. После завершения нажмите Завершить выбор групп.
  4. Выберите помещение и запустите построение.
Нумерация: углы и виды нумеруются сквозным образом по всем группам текущего помещения.

Сценарий 03

Разворот развертки 180

Команда создает корректный повернутый вариант фасада относительно выбранной линии и сохраняет настройки вида.

  1. На плане выберите фасад, который нужно развернуть.
  2. Выберите линию, по которой создавался фасад.
  3. Нажмите Разворот развертки 180.
  4. Проверьте направление нового вида и его настройки.

Сценарий 04

Выровнять марки углов

Команда используется как финальный этап после создания или переноса разверток.

  1. Откройте план с марками углов.
  2. Нажмите Выровнять марки углов.
  3. Проверьте, что марки читаются и не перекрывают линии или подписи.
Хороший результат: все марки углов стоят ровно, читаются на плане и соответствуют созданным разверткам.
