Системные семейства и PNG пирогов

Инструкция по экспорту системных типов Revit, подготовке легенд-компонентов, выгрузке PNG пирогов и записи изображений в параметр Type Image.

Когда использовать Экспорт таблиц системных типов Экспорт PNG пирогов

Сценарий 01

Когда использовать

Команды нужны, когда требуется собрать библиотечную таблицу системных типов и связать типы с наглядными PNG-изображениями пирогов.

Подходит для категорий

  • Стены.
  • Перекрытия.
  • Потолки.
  • Крыши.

Что получится

  • CSV по категориям и общий CSV.
  • Папка ctg_system families.
  • Папка PNG_Pirogi с изображениями.
  • Заполненный параметр Type Image при загрузке PNG.

Сценарий 02

Экспорт таблиц системных типов

Команда выгружает системные типы в CSV. Для пользователя это основной источник данных для HTML-просмотра и дальнейшей проверки библиотеки.

  1. Откройте проект Revit, из которого нужно выгрузить системные типы.
  2. На ленте SAB откройте модуль Библиотека.
  3. Нажмите Экспорт системных.
  4. Выберите рабочую папку для результата.
  5. После завершения откройте папку ctg_system families и проверьте CSV-файлы.

Сценарий 03

Экспорт PNG пирогов

PNG создаются с подготовленного вида Легенда. Сначала нужно расставить легенд-компоненты, затем экспортировать изображения.

Подготовка вида

  1. Откройте вид категории Легенда.
  2. Нажмите Расставить комп. легенды.
  3. Проверьте, что компоненты размещены и не перекрывают друг друга.

Экспорт PNG

  1. На этом же виде нажмите Экспорт PNG пирогов.
  2. Выберите папку результата.
  3. Проверьте папку PNG_Pirogi.
Проверка: имена PNG должны совпадать с именами типоразмеров. Если имя файла отличается, последующая загрузка в Type Image может пропустить тип.

Сценарий 04

Загрузка PNG в Type Image

Команда сопоставляет имя PNG без расширения с именем типоразмера и записывает изображение в параметр типа.

  1. Нажмите Загрузить PNG пироги.
  2. Выберите папку с PNG-изображениями.
  3. Дождитесь сообщения о результате.
  4. Откройте несколько типов и проверьте параметр Type Image.
Если совпадения нет: тип пропускается и фиксируется в отчете. Обычно причина в переименовании типа после экспорта PNG или в лишних символах в имени файла.
