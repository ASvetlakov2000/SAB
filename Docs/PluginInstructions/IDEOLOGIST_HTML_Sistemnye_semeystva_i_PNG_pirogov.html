Системные семейства и PNG пирогов

Экспорт системных типов Revit, подготовка CSV и работа с изображениями пирогов.

Описание Экспорт системных Экспорт PNG пирогов

Описание плагина

Модуль Библиотека.

Команды помогают выгрузить системные типы, подготовить данные в таблицах и связать типы с PNG-изображениями пирогов.

Рабочий процесс модуля: сначала экспортируйте данные из Revit, затем обработайте CSV/XLSX в Excel или LibreOffice, после этого используйте результат для проверки, переименования, удаления, размещения или HTML-просмотра.

Для системных семейств отдельный рабочий процесс связан с пирогами: легенд-компоненты размещаются на виде легенды, экспортируются в PNG и затем записываются в параметр Type Image.

Команда 01

Экспорт системных.

Команда выгружает системные типы в CSV по категориям и создает общий источник данных для проверки библиотеки.

  1. Откройте проект Revit с системными типами.
  2. На панели Библиотека нажмите Экспорт системных.
  3. Выберите рабочую папку для результата.
  4. Откройте папку ctg_system families и проверьте CSV-файлы.
  5. При необходимости откройте CSV в Excel или LibreOffice, исправьте наименования, удалите лишние строки или подготовьте таблицу для просмотра.

Команда 02

Экспорт PNG пирогов.

Команда создает PNG из легенд-компонентов пирогов, размещенных на виде категории Легенда.

Подготовка легенды

  • Откройте вид категории Легенда.
  • Нажмите Расставить комп. легенды, чтобы разместить легенд-компоненты по категориям.
  • Проверьте, что компоненты не перекрывают друг друга и читаются в рамке экспорта.

Экспорт изображений

  • На подготовленном виде нажмите Экспорт PNG пирогов.
  • Команда сохранит изображения в папку PNG_Pirogi.
  • Имя PNG должно совпадать с именем типоразмера, иначе следующая команда не сможет сопоставить файл с типом.

Команда 03

Загрузить PNG пироги.

Команда сопоставляет имя файла PNG с именем типоразмера и записывает изображение в параметр Type Image.

  1. Нажмите Загрузить PNG пироги.
  2. Выберите папку PNG_Pirogi.
  3. Дождитесь итогового уведомления.
  4. Откройте несколько типов и проверьте параметр Type Image или Изображение Типоразмера.
Важно: если тип был переименован после экспорта PNG, изображение может не загрузиться. Сначала синхронизируйте имена, затем повторите загрузку.
