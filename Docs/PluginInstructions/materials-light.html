Обе кнопки находятся в панели Библиотека.

1) Экспорт имен MTL

Описание команды: команда Экспорт имен MTL выгружает материалы в XLSX для пакетного обновления имен и параметров материалов.

Команда

Экспорт имен MTL

  1. Выберите рабочую папку.
  2. Проверьте файл XLSX в папке name.
  3. Откройте XLSX для редактирования.

Колонки XLSX

  • Старое/Новое имя материала
  • Старое/Новое описание
  • Изготовитель, Модель, Ключевая заметка, Маркировка
  • Удалить (1/0)
[Скриншот] XLSX материалов после экспорта.

2) Импорт: команда «Переименовать материалы»

Описание команды: команда Переименовать материалы применяет изменения имен и параметров материалов, а при флаге удаления удаляет целевые материалы.

Действия

  1. Нажмите Переименовать материалы.
  2. Выберите XLSX файл.
  3. Дождитесь сообщения об итогах обработки.

Что меняется

  • Имя материала.
  • Описание.
  • Поля: Изготовитель, Модель, Ключевая заметка, Маркировка.
  • Удаление материалов при «Удалить=1».

3) Ошибки и отчеты

Описание результата: если часть строк не удалось обработать, команда продолжает работу и формирует отчет только по проблемным записям.

  • Если строка не может быть обработана, процесс продолжается по следующим строкам.
  • Отчет ошибок сохраняется рядом с импортируемым файлом.
  • Основной отчет: Проблемные наименования.csv.
Перед массовым удалением материалов обязательно сохраните резервную копию модели.
[Видео] Переименование и удаление материалов по XLSX.
Рекомендуется выполнять в два прохода: сначала переименование/обновление полей, затем удаление по флагу.
