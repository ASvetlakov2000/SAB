Описание плагина

Стандарты наименования.

Команда открывает HTML-регламенты с правилами именования Revit-объектов.

Используйте раздел, когда нужно проверить формулу имени, расшифровку блоков, примеры и ограничения стандарта.

Регламенты открываются отдельной кнопкой и не связаны с инструкциями: это самостоятельный набор HTML-документов.

Команда

Открыть стандарты.

Команда ищет HTML-регламенты в настроенных папках и открывает стартовую страницу.

  1. На панели Регламент нажмите Стандарты Наименования.
  2. Откройте нужный регламент: системные семейства, загружаемые семейства, материалы, размеры, текстовые примечания или модели.
  3. Перейдите к нужному разделу через навигацию в шапке документа.
  4. Сверьте имя объекта с формулой, подставленными значениями, расшифровкой и правилами.
SAB. Документ оформлен в рабочем HTML-шаблоне.
