Экспликации дверей и окон.

Создайте виды дверей, окон и витражей, при необходимости разместите их на листе и выгрузите изображения.

Порядок работыЕсли не получилось

Перед началом.

Подготовьте двери, окна или витражи в модели. Можно заранее выделить нужные элементы; список уточняется при запуске.

Для полного сценария нужна основная надпись. Для размеров и подписей подготовьте соответствующие типы и шаблоны видов.

Порядок работы.

  1. Нажмите SAB → Экспликации → Экспликации дверей и окон. Завершите подготовку списка выбранных элементов по запросам плагина.
  2. В Сценарий работы выберите Полная экспликация: 3 вида и лист или Только вид и изображение, без листа.
  3. Проверьте ориентацию, Масштаб, Шаблон вида и границы. Для листа укажите Основная надпись и Тип заголовка.
  4. При необходимости включите Образмеривать фасадный вид и Экспортировать PNG и записывать в параметры. Проверьте соответствующие настройки.
  5. Нажмите Создать. Выполните дополнительные запросы выбора точки или контура. Прочитайте отчёт и откройте созданные виды.

Выберите свой сценарий.

Раскройте только нужный раздел.

Полная экспликация
  1. Выберите Полная экспликация: 3 вида и лист. Настройте общий лист, основную надпись, тип заголовка и размещение. Проверьте комплект из трёх видов.
Один вид без листа
  1. Выберите Только вид и изображение, без листа, затем Фасадный вид, Вид сверху или Разрез по центру. Настройте экспорт PNG, если он нужен.
Витраж
  1. Для наружной стороны выберите подходящий режим. При Автоматически — от точки внутри здания после настроек укажите точку внутри здания.
  2. Для границ можно выбрать Автоматически по элементу или По линиям контура на развертке. Во втором случае выполните запросы выбора контура.

Проверка результата.

  1. Начните с одного элемента. Проверьте лицевую сторону, обрезку, масштаб и видимость соседних элементов.
  2. Проверьте размеры, лист, PNG и значения параметров изображений, если эти операции включены.

Если не получилось.

Что произошлоЧто проверить
Не создан листПроверьте полный сценарий и наличие основной надписи. В режиме только вида лист не создаётся.
Фасад смотрит не тудаПроверьте Спереди — по ориентации семейства / Сзади — с противоположной стороны. Для витража проверьте наружную сторону и выбранную точку.
В кадр попали соседние элементыПроверьте Изолировать выбранный элемент и границы вида.
Не записалось изображениеПроверьте папку PNG, выбранные параметры, их доступность для записи и отчёт.
