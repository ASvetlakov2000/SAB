Описание плагина

HTML просмотр CSV.

Команда создает локальный HTML viewer для CSV-источников SAB и подбирает профиль отображения по имени файла.

Viewer нужен для проверки библиотечных таблиц без ручной сборки HTML. Он читает CSV, показывает профильные колонки, поиск, фильтры, сортировку, миниатюры и образцы.

Чтобы увидеть пироги, миниатюры, линии и штриховки, сначала экспортируйте соответствующие PNG. Если изображения не подготовлены, viewer покажет таблицу, но в ячейках превью будут пустые места или сообщение о ненайденном файле.

Команда

Открыть HTML просмотр.

В окне нужно выбрать CSV и проверить профиль просмотра.

  1. На панели Библиотека нажмите HTML просмотр.
  2. В блоке Профиль просмотра оставьте автоматически определенный профиль или выберите его вручную.
  3. Нажмите Выбрать источник и укажите CSV-файл.
  4. Нажмите Открыть просмотрщик.
  5. В открывшемся HTML используйте поиск, фильтры, сортировку, настройку видимых колонок и кнопку сброса настроек.

Что нужно для полного просмотра.

CSV открывается сам по себе, но визуальные поля появляются только при наличии подготовленных изображений.

ПрофильЧто открытьЧто подготовить заранее
Системные семействаCSV из папки ctg_system families.Для пирогов экспортируйте PNG пирогов и заполните путь в колонке Миниатюра.
Загружаемые семействаCSV из папки ctg_loadable families.Экспортируйте PNG семейств, чтобы viewer показал миниатюры.
ЛинииCSV LineStyles.Сначала выполните размещение линий и экспорт PNG линий.
ШтриховкиCSV FillPatterns.Сначала выполните размещение штриховок и экспорт PNG штриховок.
Пути к изображениям: viewer читает поля Миниатюра, ThumbnailPath, Thumbnail и IconPath. Относительные пути считаются от папки выбранного CSV.
