Библиотека

HTML просмотр CSV

Инструкция по открытию CSV-источников в профильном HTML viewer для системных, загружаемых семейств, линий и штриховок.

Что делает команда Как открыть CSV Проверка профиля по имени файла

Сценарий 01

Что делает команда

Команда открывает CSV-источник в отдельном HTML viewer и автоматически выбирает профиль отображения по имени файла.

Поддерживаемые профили

  • Системные семейства.
  • Загружаемые семейства.
  • Линии.
  • Штриховки.

Что показывает viewer

  • Табличные данные из CSV.
  • Миниатюры PNG, если они есть.
  • Поля, важные для проверки библиотеки.

Сценарий 02

Как открыть CSV

Сценарий одинаковый для всех профилей. Главное - выбрать корректный CSV, созданный командами SAB.

  1. Нажмите HTML просмотр на панели Библиотека.
  2. Нажмите Выбрать источник.
  3. Укажите CSV-файл.
  4. Проверьте выбранный профиль по имени файла.
  5. Нажмите Открыть.

Сценарий 03

Проверка профиля по имени файла

Viewer выбирает логику отображения автоматически, поэтому имя CSV должно соответствовать типу выгрузки.

Фраза в имени CSVПрофильЧто проверить
Системные семействаСистемныеКатегория, структура, толщина, миниатюра.
Загружаемые семействаЗагружаемыеКатегория, семейство, типоразмер, PNG.
ЛинииЛинииНаименование, вес линии, цвет, образец.
ШтриховкиШтриховкиПередний план, задний план, маскирование, тип.
