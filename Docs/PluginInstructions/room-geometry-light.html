Проверка геометрии помещений

Кнопка находится в панели Помещения и открывает окно Room Geometry Tools.

1) Что делает команда

Описание команды: открывает рабочее окно для проверки углов помещений, проверки неразмещенных помещений, контроля изменения площади и построения осей помещений на активном виде.

  • Проверка углов помещений.
  • Проверка неразмещенных помещений.
  • Проверка отклонения площади от утвержденной.
  • Создание осей по выбранному помещению или по всем помещениям активного вида.

2) Как пользоваться

Стандартный сценарий проверки

  1. Нажмите Проверка геометрии помещений.
  2. Задайте порог отклонения площади, %.
  3. Запустите проверки по кнопкам окна.
  4. Проверьте вкладки с результатами.

Сценарий построения осей

  1. Выберите стиль линии осей.
  2. Выберите помещение или запустите обработку всех помещений на активном виде.
  3. Проверьте созданные оси и сводку по пропущенным помещениям.
Если проверка показывает ошибки геометрии, сначала исправьте помещение, затем повторите построение осей.
