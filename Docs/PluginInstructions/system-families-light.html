1) Экспорт таблиц системных типов

Описание команды: команда Экспорт системных выгружает только системные типы (Стены, Перекрытия, Потолки, Крыши) в CSV по категориям и общий CSV.

Команда

Экспорт системных

  1. Выберите рабочую папку.
  2. Проверьте создание папки ctg_system families.
  3. Проверьте CSV по категориям и общий CSV.

Категории в выгрузке

  • Стены
  • Перекрытия
  • Потолки
  • Крыши
Только эти категории считаются системными для данного экспорта.

2) Экспорт PNG для системных типов

Описание команды: команда Экспорт PNG пирогов экспортирует изображения системных типов с подготовленного вида Легенда в папку PNG_Pirogi.

Подготовка

  1. Откройте вид Легенда.
  2. Командой Расставить комп. легенды подготовьте легенд-компоненты.
  3. Запустите Экспорт PNG пирогов.

Результат

  • Создается папка PNG_Pirogi.
  • Имена файлов должны соответствовать именам типоразмеров.
  • При проблемных именах создается отчет по проблемам.
[Видео] Подготовка легенды и экспорт PNG пирогов.

3) Загрузка PNG в параметр типа

Описание команды: команда Загрузить PNG пироги сопоставляет имя файла PNG с именем типоразмера и записывает изображение в параметр типа Type Image.

Команда: Загрузить PNG пироги.

  • Выберите папку с PNG.
  • Сопоставление идет по имени файла без расширения = имя типоразмера.
  • Изображение записывается в системный параметр Type Image.
Если совпадения имен нет — тип пропускается и фиксируется в отчете.
[Скриншот] Результат присвоения изображения типоразмеру.
