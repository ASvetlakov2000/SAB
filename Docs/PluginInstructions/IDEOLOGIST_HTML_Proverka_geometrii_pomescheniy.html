Проверка геометрии помещений

Инструкция по запуску Room Geometry Tools: проверка углов, неразмещенных помещений, отклонения площади и построение осей.

Что делает команда Стандартный сценарий проверки Построение осей помещений

Сценарий 01

Что делает команда

Команда открывает рабочее окно для контроля качества помещений и построения осей на активном виде.

Проверки

  • Углы помещений.
  • Неразмещенные помещения.
  • Отклонение площади от утвержденной.

Построение

  • Оси по выбранному помещению.
  • Оси по всем помещениям активного вида.
  • Сводка по пропущенным помещениям.

Сценарий 02

Стандартный сценарий проверки

Запускайте проверку перед выпуском планов или перед построением осей.

  1. Откройте план, на котором нужно проверить помещения.
  2. Нажмите Проверка геометрии помещений.
  3. Задайте порог отклонения площади в процентах.
  4. Запустите нужные проверки в окне.
  5. Просмотрите вкладки с результатами и исправьте найденные проблемы.

Сценарий 03

Построение осей помещений

Оси строятся по выбранному помещению или по всем помещениям активного вида.

  1. Откройте нужный план.
  2. Выберите стиль линии осей.
  3. Выберите одно помещение или запустите обработку всех помещений активного вида.
  4. Проверьте созданные оси.
  5. Посмотрите сводку по помещениям, которые команда пропустила.
Если оси не построились: проверьте границы помещения, активный вид и наличие корректно размещенного помещения.
