Обе кнопки находятся в панели Библиотека (группы «Экспорт» и «Переименование»).

1) Экспорт имен типов

Описание команды: команда Экспорт имен типов формирует XLSX-наборы для системных, загружаемых и прочих категорий, чтобы переименование выполнялось по отдельным группам.

Что создает команда

  • XLSX «Системные семейства» (со столбцом «Структура»).
  • XLSX «Загружаемые семейства».
  • XLSX «Прочее».

Где искать файлы

  • Рабочая папка: name.
  • Имя модели включается в название файлов.

2) Правка XLSX перед импортом

Описание шага: в этом файле редактируются только целевые значения переименования и флаги удаления; столбец «Структура» служит вспомогательной информацией.

КолонкаНазначение
КатегорияКатегория типа
Старое семействоИсходное имя семейства
Новое семействоНовое имя семейства
Старый типоразмерИсходное имя типа
Новый типоразмерНовое имя типа
СтруктураТолько справочно (в системной группе)
Удалить1 — удалить тип, 0 — оставить
Не меняйте названия столбцов и общий формат файла.

3) Импорт: команда «Переименовать типы»

Описание команды: команда Переименовать типы применяет изменения построчно, а проблемные строки фиксирует в отдельном отчете без остановки всего процесса.

Действия

  1. Нажмите Переименовать типы.
  2. Выберите XLSX файл.
  3. Дождитесь итогового уведомления.

Результат

  • Переименование семейства и/или типа по строкам.
  • Удаление типов с флагом «Удалить=1».
  • При ошибках создается Проблемные наименования.csv.
Рекомендуется сначала выполнить переименование без удаления, затем отдельным проходом включить удаление по нужным строкам.
