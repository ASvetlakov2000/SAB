HTML-просмотрщик библиотеки.

Соберите просмотр каталога из CSV и изображений, чтобы проверить состав библиотеки.

Порядок работыЕсли не получилось

Перед началом.

Подготовьте выгрузки CSV. PNG можно добавить отдельно; без них часть карточек будет без изображений.

Просмотрщик допускает частичный набор и показывает его состояние.

Порядок работы.

  1. Откройте SAB → Библиотека → Библиотека и выберите «HTML-просмотрщик».
  2. Нажмите «Добавить CSV» и выберите нужные файлы. Повторите добавление для других наборов.
  3. Кнопками «Выбрать» укажите соответствующие папки изображений системных типов, загружаемых семейств, линий и штриховок.
  4. Прочитайте состояние полноты набора. Нажмите «Открыть просмотрщик».
  5. В браузере проверьте таблицы и изображения. Если данных нет, вернитесь в библиотеку и уточните выбранные файлы.

Выберите свой сценарий.

Раскройте только нужный раздел.

Заменить набор
  1. Используйте «Очистить» для CSV и «Очистить папки» для изображений. Добавьте новый набор и повторно откройте просмотрщик.

Проверка результата.

  1. Найдите несколько известных типов и сравните данные с CSV.
  2. Проверьте изображения из каждого добавленного набора. Частичный набор не означает полный каталог.

Если не получилось.

Что произошлоЧто проверить
Нет карточекПроверьте выбранные CSV. Без файлов просмотрщик показывает страницу состояния.
Нет картинокДобавьте папку PNG соответствующей категории и проверьте совпадение имён с CSV.
Браузер не открылсяПроверьте приложение по умолчанию для HTML в Windows и доступ к файлам.
