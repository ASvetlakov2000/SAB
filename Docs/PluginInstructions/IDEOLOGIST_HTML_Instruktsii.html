Заполнение параметров.

Первая инструкция общего раздела: от выбора параметра до проверки результата.

Раздел будет дополняться инструкциями по другим инструментам SAB. Здесь показаны инструкции, включённые в текущую версию справки.

Локальная справка

Всегда рядом с плагином.

  1. В Revit откройте вкладку SAB, панель Настройки и нажмите Инструкции. Этот раздел откроется в браузере по умолчанию Windows.
  2. Выберите нужную инструкцию. Внутри неё используйте навигацию по разделам; ссылка Все инструкции возвращает на эту страницу.
  3. В окне Настройки параметров кнопка Инструкция открывает сразу инструкцию этого инструмента.
Интернет не требуется. HTML и оформление устанавливаются вместе с SAB. Кнопка справки не записывает данные в модель и доступна без открытого проекта.

Обновление
Установите обновлённый SAB для своей версии Revit. Файлы справки обновятся вместе с плагином.
Если не открывается
Проверьте приложение по умолчанию для .html в Windows. Если файлы отсутствуют, повторно установите SAB.
