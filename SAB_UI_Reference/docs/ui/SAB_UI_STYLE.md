\# SAB UI Style Guide



Этот документ описывает обязательную стилистику WPF-окон решения SAB.



\## 1. Общий характер интерфейса



Интерфейс должен выглядеть как аккуратное современное окно плагина Autodesk Revit.



Требования:



\* светлая нейтральная тема;

\* белые рабочие поверхности;

\* светло-серый фон окна;

\* тонкие серо-голубые границы;

\* один основной синий акцент;

\* минимум декоративных элементов;

\* отсутствие визуального стиля веб-сайта;

\* отсутствие чрезмерных теней, градиентов и анимаций;

\* все решения должны быть реализуемы стандартными средствами WPF.



Визуальный референс:



`docs/ui/references/CreateViewsAndSheets\_reference.png`



\## 2. Цвета



Использовать общие ресурсы, а не задавать цвета непосредственно в XAML окна.



Рекомендуемая палитра:



\* фон окна: `#F7F8FA`;

\* фон панелей: `#FFFFFF`;

\* фон строки заголовков таблицы: `#F5F7FA`;

\* основная граница: `#D8DEE8`;

\* слабая граница: `#E6EAF0`;

\* основной текст: `#1F2937`;

\* вторичный текст: `#667085`;

\* основной акцент: `#0F6CBD`;

\* светлый акцентный фон: `#EAF3FF`;

\* ошибка: `#D92D20`;

\* предупреждение: `#B54708`;

\* успешное состояние: `#039855`;

\* отключённый фон: `#F2F4F7`;

\* отключённый текст: `#98A2B3`.



Перед добавлением новых цветов проверить существующие ResourceDictionary решения SAB.



\## 3. Типографика



Использовать системный шрифт решения SAB.



Если отдельный шрифт в проекте не определён, использовать:



`Segoe UI`



Размеры:



\* основной заголовок окна: 20 px, SemiBold;

\* заголовок группы: 15–16 px, SemiBold;

\* заголовки таблицы: 12–13 px, SemiBold;

\* основной текст: 12–13 px;

\* вспомогательный текст: 11–12 px;

\* текст кнопок: 12–13 px.



Не использовать текст полностью в верхнем регистре, кроме существующих обозначений и аббревиатур.



\## 4. Отступы



Использовать кратные значения:



\* 4 px — минимальный внутренний отступ;

\* 8 px — отступ между связанными элементами;

\* 12 px — стандартный отступ между полями;

\* 16 px — внутренний отступ панели;

\* 20–24 px — отступ между крупными областями.



Не задавать случайные отступы отдельно для каждого элемента.



\## 5. Основная компоновка окна



Окна с таблицами должны иметь двухколоночную структуру:



\* левая колонка — дополнительные и редко изменяемые настройки;

\* правая колонка — основная рабочая область.



Рекомендуемая ширина левой колонки:



\* обычная ширина: 320–340 px;

\* минимальная ширина: 290 px;

\* максимальная ширина: 420 px.



Правая колонка должна занимать всё оставшееся место.



Окно должно поддерживать изменение размера.



Основная рабочая область должна иметь визуальный приоритет.



\## 6. Панели



Группы настроек оформлять как светлые панели:



\* белый фон;

\* тонкая граница;

\* радиус скругления 5–6 px;

\* внутренний отступ 12–16 px;

\* расстояние между панелями 8–12 px.



Заголовок панели содержит:



\* небольшую синюю иконку;

\* текст заголовка;

\* при необходимости кнопку сворачивания справа.



Не использовать тяжёлые стандартные GroupBox с тёмной рамкой, если в решении SAB уже существует собственный стиль панели.



\## 7. Поля ввода и ComboBox



Рекомендуемая высота:



\* 30–32 px.



Требования:



\* белый фон;

\* тонкая серая граница;

\* радиус скругления 4–5 px;

\* горизонтальный внутренний отступ 8–10 px;

\* синяя граница или подсветка при фокусе;

\* отключённые поля должны иметь светло-серый фон;

\* длинные значения должны иметь Tooltip.



Подпись располагается над полем.



Поля X и Y одной сущности разрешено располагать в одной строке.



\## 8. RadioButton и CheckBox



Использовать синий цвет активного состояния.



RadioButton для выбора способа ввода располагаются горизонтально:



\* `Ручной ввод`;

\* `Указать точку`.



При выборе `Ручной ввод` поля X и Y доступны.



При выборе `Указать точку` поля X и Y должны становиться недоступными или отображать значение выбранной точки.



\## 9. Таблицы



Использовать DataGrid.



Требования:



\* тонкие разделители;

\* светлый фон заголовка;

\* высота строки около 38–42 px;

\* спокойное выделение строки светло-синим цветом;

\* отсутствие тяжёлой стандартной рамки;

\* колонки с текстом должны растягиваться;

\* служебные колонки имеют фиксированную ширину.



Колонки основной таблицы:



\* №;

\* Имя вида;

\* Масштаб;

\* Шаблон вида;

\* № листа;

\* Имя листа;

\* Действия.



\## 10. Кнопки действий строки



Порядок кнопок:



1\. переместить строку вверх;

2\. переместить строку вниз;

3\. добавить строку после текущей;

4\. удалить строку.



Кнопки должны быть:



\* квадратными;

\* компактными;

\* одинакового размера;

\* с простыми монохромными иконками;

\* без текстовых подписей;

\* с Tooltip.



Рекомендуемые Tooltip:



\* `Переместить строку вверх`;

\* `Переместить строку вниз`;

\* `Добавить строку ниже`;

\* `Удалить строку`.



Для первой строки кнопка перемещения вверх должна быть отключена.



Для последней строки кнопка перемещения вниз должна быть отключена.



Удаление последней оставшейся строки должно быть запрещено или должно автоматически создавать одну пустую строку.



\## 11. Основные кнопки окна



В нижней правой части окна использовать порядок:



1\. `Проверить`;

2\. `Отмена`;

3\. `Создать`.



\### Кнопка «Создать»



Главная акцентная кнопка:



\* сплошная синяя заливка;

\* белый текст;

\* заметнее остальных кнопок;

\* ширина около 110–130 px;

\* высота около 34–38 px.



\### Кнопка «Проверить»



Вторичная акцентная кнопка:



\* белый фон;

\* синяя рамка;

\* синий текст.



\### Кнопка «Отмена»



Нейтральная кнопка:



\* белый или светло-серый фон;

\* серая рамка;

\* основной тёмный текст.



Не использовать синюю заливку одновременно для кнопок `Проверить` и `Создать`.



\## 12. Сообщения и валидация



Под основной таблицей размещать отдельную панель сообщений.



Состояния:



\* информационное;

\* успешное;

\* предупреждение;

\* ошибка.



Для ошибки использовать:



\* красную иконку;

\* заголовок `Ошибки:`;

\* список понятных сообщений.



Пример:



`Нет заполненных строк для создания.`



В нижней левой части окна показывать строку состояния:



`Строк: 1 | Заполнено: 0 | Ошибок: 1`



\## 13. Иконки



Сначала использовать уже существующие иконки и ресурсы решения SAB.



Не добавлять новую библиотеку иконок только ради одного окна.



Иконки должны быть:



\* простыми;

\* контурными;

\* монохромными;

\* визуально одинаковой толщины;

\* размером примерно 14–18 px.



\## 14. Правила реализации



\* Все общие цвета должны находиться в ResourceDictionary.

\* Все общие стили контролов должны находиться в ResourceDictionary.

\* Не задавать локально цвета и размеры, если для них существует ресурс.

\* Не копировать один и тот же Style в разные окна.

\* Не изменять логику ViewModel ради визуального оформления.

\* Не переносить обработчики команд из ViewModel в code-behind.

\* Не добавлять сторонние UI-библиотеки без отдельного согласования.

\* Перед созданием нового стиля сначала проверить существующие ресурсы SAB.

\* Новое окно должно визуально соответствовать референсу, но оставаться реализуемым на текущей версии WPF и .NET решения.
