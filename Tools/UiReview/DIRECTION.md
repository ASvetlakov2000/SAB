# Test redesign contract

Operate. Inherit the user-selected SAB UI Lab visual world and extend the real workflows. Color: window #F7F8FA, surface #FFFFFF, ink #1F2937, secondary #667085, boundary #D8DEE8, accent #0F6CBD. Segoe UI: 24 task, 16 section, 13 body, 12 supporting. White flat work surfaces; 1 DIP boundaries, 8 DIP panels, 5 DIP inputs. No decorative shadows or gradients.

First viewport: selected source is explicit; editable working rows dominate the right side; scoped settings stay in a 320-DIP left column with local navigation. A fixed text preview explains the selected result without a diagram. Parameter rules use the same arrangement, with selected-rule source settings alongside the rules table. Footer names the task action and indicates test mode.

Signature interaction: selecting a working row immediately reveals its text result and, for parameterization, its source editor. Switching settings preserves entered values and scroll state because the sections are cached. No simulated model operation can be mistaken for a Revit transaction.

Motion: opening 180 ms / 6 DIP; instrument and setting changes 140 ms / 4 DIP; disclosure 150 ms / 3 DIP; selected preview 160 ms; feedback 140 ms; button hover 100 ms and press 70/100 ms. Use render transforms and opacity, never animated layout dimensions. Honor OS reduced-motion and the in-app switch; interruption resets visible base values. These are the previously agreed implemented motion families, not every possible effect offered by the skills.

Review: three primary captures at 1400×900 DIP; all three at 1100×700 DIP; parameter source, values, categories and auxiliary elevation/sheet settings captures. Check a 192-DPI bitmap separately; it is not proof of physical monitor transitions. Native WPF QA, no HTML detector. No approved comp; reference is the previous LAB native captures. User approval comes before production changes.
