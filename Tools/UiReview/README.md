# SAB — тестовые окна для согласования

10 октября 2026. Это отдельное приложение WPF UI 4.3 / .NET Framework 4.8 с демонстрационными данными. Рабочие окна, XAML, сборки и установка SAB не изменены.

## Запуск

Откройте `Open-Elevations.cmd`, `Open-Views-And-Sheets.cmd` или `Open-Parameters.cmd`. Все три окна доступны также через верхнее меню тестового приложения. Исполняемый файл: `dist/SAB.UI.Review.exe`.

Можно редактировать таблицы одним кликом, выбирать строки, добавлять и удалять их, искать, переключать разделы и проверять текстовый результат. Состояние сохраняется при переключении в пределах открытого приложения; после закрытия демонстрационные данные сбрасываются. Кнопки выбора в Revit и переноса файлов показывают пояснение о тестовом режиме. Они не запускают операции в рабочем проекте.

«Тест создания» проверяет таблицу и показывает результат симуляции. «Тест сохранения» проверяет профиль, не записывая его в SAB. Наборы настроек представлены для согласования компоновки; бизнес-логика всех полей ещё не подключена.

## Что согласовываем

- Развёртки: источник помещения и контура, настройки видов/листа/план-схемы/марок, рабочий комплект, текстовый предпросмотр.
- Виды и листы: образцы, положение видов и заголовков, состав копирования, структура, редактируемая таблица и текстовый результат.
- Параметризация: правила, редактор выбранного источника, общие источники, значения и сопоставления, категории. Ручной выбор помещения сохранён по умолчанию. Настройки и заполнение элементов разделены.

Иллюстрации листов и схем развёрток отсутствуют. Поля используют одну скруглённую рамку; активная рамка синяя, при ошибке красная. Для формы предусмотрен отдельный 12-DIP отступ полосы прокрутки.

Анимации открытия, переключения, раскрытия, предпросмотра, обратной связи и кнопок работают в приложении. Переключатель «Анимации» отключает пользовательские эффекты; учитывается системная настройка анимации Windows. Размеры компоновки не анимируются.

## Проверка

`Build.ps1 -Verify` собирает приложение, создаёт снимки в `outputs` и выполняет 24 проверки. Последний результат — `outputs/verification.txt`: одиночная рамка, цвет фокуса, числовая валидация включая скрытые разделы, предпросмотр в маленьком окне, белые подписи синих кнопок, сохранение выбранных источников и правок, проверка повторяющихся номеров, виртуализация 2006 правил (7 видимых контейнеров), завершение прерванной анимации.

Проверка через Windows computer-use подтвердила запуск приложения, редактирование ячейки, обновление текстового предпросмотра и сохранение изменённого имени при переключении инструментов. Проверка проводилась на тестовых данных. Выполнение внутри Revit и переход между мониторами с разным DPI пока не проверялись; `parameters-192dpi.png` — рендер WPF в bitmap.

## Следующий этап

Согласовать каждое окно с пользователем. После подтверждения конкретного окна перенести его компоновку и привязки в рабочий SAB и проверить сборки Revit 2022/2023/2024. Дополнительные диалоги согласуются отдельно. Этот проект не содержит установщика для Revit и не меняет модель.
