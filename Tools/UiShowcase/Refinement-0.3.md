# Правки пользователя 0.3 — до реализации

Исходная логика остаётся из SAB. Разрешённое дополнение: показать выбранные категории, сохранить/загрузить выборку; это реальные действия над CategoryChoice.Selected, без Document. Правила распространяются на общие компоненты обоих примеров и будущие согласованные окна; массовая production-миграция не запрошена.

Сравнены две схемы: горизонтальная лента всех настроек и прежняя sidebar/table. Выбрана sidebar/table: не сокращает таблицу по высоте, сохраняет исходные условные разделы. Sidebar расширяется до 380 DIP, отдельная карточка на каждый заголовок. Никаких иконок/шевронов у заголовков: разделы постоянно раскрыты, условная Visibility остаётся исходной.

Виды/листы:
```
title + framed instructions                 settings
[structure capsule]  [table title + toolbar          ]
[sample card      ]  [header | 44 DIP rows | actions ]
[placement card   ]  [                               ]
[copy card        ]  [original validation            ]
fixed footer: status                         cancel/create
```

Параметры: четыре вкладки только по ширине заголовков; toolbar как у видов/листов, 34 DIP кнопки, 8 DIP gap. Все DataGrid используют одни row/cell/actions styles. Строки 44 DIP; подробные данные выбранного параметра в framed explanation, dropdown сохраняет GUID/тип/группы. Добавление через плюс в строке; прежняя кнопка добавления видна только как плюс для пустой таблицы. Пояснения и примеры — общий светлый блок с рамкой, padding12, gap12. Подвал с пояснением отдельно от кнопок.

Категории: поиск; Все/Выбранные capsule; Сохранить выборку/Загрузить выборку; текущие массовые действия; список и счётчик. JSON имеет format/version и стабильные category IDs. Загрузка заменяет выборку, неизвестные IDs пропускает с явным счётчиком; неверный файл не меняет выбор. Отмена диалога ничего не меняет. Ошибки отображаются в самом контроле. Сохранение через временный файл и замену.

Кнопки действий: 28×28 DIP, gap8, padding столбца8, центр по вертикали, явный header «Действия». Единая шкала:8 controls,12 information,16 card,20 columns,24 page. Отдельные карточки разделов и панели пояснения явно запрошены пользователем и приоритетны над общим запретом карточной композиции в skill.

Проверка: целевая Revit2023/net48 сборка, актуальные normal/minimum/144dpi и все четыре вкладки/три структуры, капсула и её реальный VM, сохранение/загрузка/неизвестные/битый файл, отсутствие повторных add при непустой таблице. Старые 0.2 снимки сохраняются; новые — screenshots-v0.3. Системный DPI, Revit Document и транзакции не заявляются.
