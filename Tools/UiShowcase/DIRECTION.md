# Направление тестового интерфейса

Mode: Operate. Code-led: реальные WPF-концепции по прямому запросу пользователя; растровые макеты не используются как доказательство запуска.

Первый экран сразу показывает сопоставление «сущность → параметр → источник» и основное действие. Сигнатурное взаимодействие — поиск реального параметра в составном поле с метаданными, без ухода из редактируемой строки.

Визуальная основа задана пользователем: Fluent Light / Fluent Compact / Minimal SaaS. Предложение Unified сохраняет синий SAB #0F6CBD, нейтральные светлые поверхности, Segoe UI, компактную сетку и сдержанное использование рамок. Типографика не копирует веб-лендинг.

Проверяемый уровень качества: одна рамка активного ввода; видимый фокус; читабельные 13/12 DIP; доступная прокрутка и последний столбец; ошибки рядом с действием и в поле; одинаковый набор данных во всех концепциях; реальное открытие и рендер при 100/150%.

Ограничение: адаптированная тестовая версия эталона, а не утверждённый перенос production-окна. Концепции равноправны для сравнения; рекомендуемый Unified требует одного решения пользователя.

THESIS: инженер сравнивает назначения в одной таблице, не теряя источник и область применения.
OWN-WORLD: светлый Windows WPF, Segoe UI, синий SAB, реальные параметрические данные и метаданные.
STORY: правило → источник → преобразования значений → категории → проверка/сохранение.
FIRST VIEWPORT: заголовок, конфигурационные действия, четыре раздела, редактируемая таблица, закреплённое основное действие.
FORM: Tabbed Workspace; 32 DIP поле, 60 строка с метаданными, тонкие горизонтальные разделители; нейтральные второстепенные действия.

Concept-seed выполнен в этой сессии до реализации: direction / operate, ключ `c79b92d6`, assigned 7. Запрос пользователя прямо задаёт три Fluent Light / Fluent Compact / Minimal SaaS и однократное согласование; эта более точная инструкция имеет приоритет над случайной сменой визуального мира. Каталожные challengers split-flap concourse, orienteering map и Japanese high-density не используются как чужие оболочки. Их дисциплины учитываются без декоративных мотивов: выравнивание повторяющихся записей, ясная навигация, сохранение плотности без уменьшения основного текста. UI UX Pro Max дал веб-схемы Hero/Features/CTA и несоответствующие палитры; они отклонены, применена лишь релевантная рекомендация видимого keyboard focus.

QUALITY BAR: сравнение имеет одинаковые данные и структуру; нет обрезанного основного действия на минимуме; в таблице доступна прокрутка; составной поиск независим между строками; ошибка объясняет исправление; статус preview не смешивается с production. Системный DPI 96 и RenderTargetBitmap 144 dpi явно разделены в протоколе. Никакого утверждённого comp нет: это code-led концепции для будущего выбора.
