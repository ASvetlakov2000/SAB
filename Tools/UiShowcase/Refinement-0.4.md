# Уточнения 0.4 — план до реализации

Сохраняется Fluent Light, реальные source-модели, Binding и обработчики. Production не изменяется.

Сравнение схем: общий ScrollViewer вокруг карточек экономит код, но режет их рамки у footer. Выбрана ограниченная рабочая область: неподвижная рамка вокруг прокручиваемого содержимого; категории без внешней прокрутки, список занимает остаток высоты. Длинные источники и значения прокручиваются внутри рамки с мягким краем продолжения.

Wireframe параметров: бренд → заголовок + пояснение → капсулы вкладок34 → содержимое → нижняя строка статуса → нижний ряд Инструкция / Конфигурация: Импорт, Экспорт | Отмена, Сохранить. Категории: слева карточка области с группами Вид / Выборки / Выделение, подсказкой, поиском непосредственно над списком; справа отдельная карточка опций обработки. Никакой полосы вкладок во всю ширину.

Виды: структура и секции в ограниченной области настроек; таблица и проверка справа; обмен настройками в нижней панели. Вторичное окно настроек: две ограниченные области с отдельными смысловыми секциями, без иконок заголовков, те же капсулы и footer.

Геометрия: кнопки/поля/капсулы34 DIP; индикатор капсулы30, внутренний отступ2. Таблица44, header38; действия28, gap8. Поля зоны и кнопки отдельной строки Grid с общим вертикальным центром. Общий левый край текста столбца10 DIP; числовые заголовки и содержимое по центру. Скруглённые таблицы получают действительный RectangleGeometry clip, не прямоугольный ClipToBounds.

Проверка: реальные сборка и WPF-снимки обычного/минимального размеров, состояния и вторичное окно; source-contract, сохранение выборок; автоматические проверки размеров, центров и clipping. Проверка в Revit сюда не входит.

## Последнее уточнение: инструкции вне окон

Общий шаблон теперь: бренд → заголовок без описания модуля → вкладки/рабочее содержимое → фактический статус → footer с «Инструкция» и действиями. Удаляются также обучающие абзацы в карточках и вкладках. Вместо повторения текста в окнах кнопка открывает локальный HTML соответствующего модуля. Метаданные выбранного правила, ошибки, результаты проверки и операций остаются. Это заменяет прежнее требование помещать инструкции в рамки; распространяется на все активные и следующие шаблоны, включая secondary settings. Исторические исключённые шаблоны и production не мигрируются.
