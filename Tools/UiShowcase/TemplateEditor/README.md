# Редактор шаблонов — изолированный WPF-предпросмотр

Этап1 от17.10.2026, **правки2**. **Тестовые данные. Не production и не Revit.** Действующая компоновка: вертикальный выбор шаблонов слева, настройки справа;7вкладок. Предыдущая ревизия сохранена отдельно.

Запуск: `Open.cmd` открывает готовую сборку. Повторный запуск активирует тот же экземпляр. Если артефакта ещё нет, выполняется первая сборка. Для разработки: `Build.ps1 -Capture` или `Build.ps1 -Open` (закрыть запущенный экземпляр перед пересборкой).

Файлы макета: `Views/*.xaml`; функциональная структура берётся из исходных `SAB/Cls_ViewTemplateGraphics`. `Prepare.py` генерирует только изолированные C# в существующем `outputs/ui-production-preview/template-editor/source`: другой namespace, два Document/Collect-пути заменены Fixtures, TaskDialog представлен validation-строкой, сохранение геометрии отключено. Модели и search/order/copy-edit handlers сохранены; новый preview capability guard ограничивает category batch текущей доступной секцией/полутонами. `GraphicOverrideEditorWindow` имеет только presentation height adjustment. Common dictionary подключён непосредственно из `SAB/UI/Styles/SABFluentLight.xaml`, не скопирован; Application.Resources пуст. `SAB.dll` нужен для существующих shared FluentLight attached components. При отсутствии общей сборки Build собирает неизменённые production sources в канонический plugin-каталог.

`source-contract.json` перечисляет baseline hashes и все исходные Binding/Command/x:Name/Tag/columns. Внутренний `TabBorder` старого ControlTemplate заменён общим TabItem template; функциональные имена обработчиков не менялись. `CreateDesign.py` — воспроизводимый derivation layout, не production migration. `PreviewShell` добавляет только явно требуемые footer help, безопасный Enter для исходных search actions, Escape/IsCancel и preview validation presentation. Revit services/commands/transactions в этот exe не включены.

Интерактивно доступны7вкладок, тип/поиск шаблонов, галочки целей отдельно от Extended highlight, mixed/dirty guard, category tree/search/batch, графические sectional editors, filter picker/remove/order и worksets. По прямому feedback удалена сущность отдельных связей; общая видимость OST_RvtLinks представлена в «Модели».
